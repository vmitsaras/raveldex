# Source ownership

RX-1001 implements internal input contracts, the shared analyzer, error codes and limit guards. RX-1002 adds frequency-only index construction, exact normalized-term lookup and invariant diagnostics. RX-1003 adds complete typed query evaluation, native BM25 and actual numerical trace facts. RX-1004 adds incremental delta staging and atomic core/participant publication. RX-1005 implements the ordinary engine/factory. RX-1006 exports the real factory, errors and readonly contract types from `index.ts`, returning only bound ordinary methods through a frozen facade. The compiler emits ESM and declarations to `dist/`; the root package is qualified through an isolated tarball consumer.

`contracts/` captures frozen bounded structures before any resumable content scan. `analyzer/basic.ts` emits work steps and original-value token spans; consumers must completely validate an operation before publishing state. `analyzeRecord` and `analyzeQuery` share that raw analyzer. `limits/` defines all hard caps and pure guards for later state, expansion and execution integration. These guards do not establish live index or scheduler behavior.

`index/` owns sparse 256-slot, prototype-safe bucket directories, field-local frequencies/statistics and reverse document terms. Internal `IndexConstruction.append` captures one bounded batch synchronously and returns charged analysis/staging work; `finish` returns a deeply frozen root only after complete consumption. An abandoned/failed cursor invalidates the entire construction. `retrieval/exact.ts` accepts a normalized term and selected declared fields, returning complete owned membership without a ranking/order contract. Source, position, offset and occurrence records are absent. `index/staging.ts` now coalesces touched buckets for incremental revisions. `execution/engine.ts` owns promise/queue semantics.

`query/search.ts` synchronously captures raw queries/options and an optional private trace request, then returns one generator using a shared work budget. `query/compile.ts` consumes the shared analyzer once, preserves normalized term identity and deduplicates equivalent scoring groups. `retrieval/expand.ts` enumerates complete exact/prefix expansions, counting distinct field/term pairs per group and across the whole query. `query/evaluate.ts` retains positive groups only from successful Boolean branches. `ranking/bm25.ts` computes the versioned field-local formula; `ranking/page.ts` uses a resumable worst-first heap of at most offset + limit entries. `trace/facts.ts` allocates a collector only for an explicit selected-ID request, rejects mismatched revisions, and caps complete header/facts at 4,096. This is a private Inspector integration seam, not a new public search option or installed add-on. `captureSearch` owns the request independently of root selection; `executeOwnedSearch` accepts private stop checks within dictionary/posting/evaluation/scoring/selection loops. Ordinary engine operations enforce signals and admission-time deadlines.

`mutations/owner.ts` owns a single frozen current root and admits one internal cursor at a time. Input capture shares one structural budget with options; execution selects the then-current root, prepares only supplied changed records and subtracts old reverse frequencies. `mutations/delta.ts` updates live counts/statistics and seals changed directories under the same work budget. Installed trusted `revision/participant.ts` handles prepare immutable side roots with charged cursors; the owner publishes every root/revision with one assignment after a final stop check. No participant action runs after commit. No-op calls avoid callbacks/revisions, failures and abandoned cursors release private staging, and revision exhaustion rejects changing writes. The private seam takes coherent supplied initial roots; it does not recover source retroactively. RX-2001 exposes validated direct registration using an owned-data/revision bridge, without exposing core roots to handles. `execution/engine.ts` integrates the mutation/query cursors under one bounded FIFO. Options and inputs share one admission counter; closed/already-aborted calls skip caller data. Deadlines use `performance.now()` and include queue time. Stops precede work-limit errors; final precommit reads recheck closing and latched aborts after structural host handles can reenter. Once a cursor returns a committed result, cleanup cannot revoke it. `execution/host.ts` lazily binds monotonic clock/timer handles only at explicit factory creation and schedules actual host tasks. Disposal rejects waiters, closes suspended staging, removes timers/listeners/continuations and releases the root. Private count diagnostics measure whole pump bursts across consecutive FIFO calls; a final bounded charge can overshoot the configured host-yield quantum.

| Path | Ownership |
| --- | --- |
| `core/` | Data/analysis, native dictionary/postings, typed queries/ranking, mutation and execution contracts. |
| `addons/phrases/`, `addons/positions/` | Strict phrase strategies and optional side-index detail. |
| `addons/filters/`, `addons/facets/` | Optional structured matching and complete aggregation. |
| `addons/evidence/`, `addons/inspector/`, `addons/ui/` | Original-text evidence, factual diagnostics, optional native DOM presentation. |
| `adapters/worker/`, `adapters/snapshots/`, `adapters/indexeddb/` | Explicit host, serialization, and persistence capabilities. |

`src/index.ts` exposes the implemented core contract. Do not create a success-returning placeholder factory or re-export optional modules from the core barrel. DOM types are deliberately absent from the root core TypeScript configuration.

RX-2001 `core/capabilities/` captures complete bounded manifests, dependency-orders narrow handles and meters all refinements under the shared search budget. `addons/phrases/source.ts` exports only the optional source factory; private `store.ts` retains selected originals in coherent immutable roots. `verifier.ts` streams the native analyzer with a 32-entry prefix table; `index.ts` supplies a leaf refiner. Core compiles the phrase once, retrieves complete lexical groups, refines its own leaf, and retains only successful lexical score groups. Source/verification never enter the root import graph. Internal initial construction rejects add-ons; supported initialization uses the ordinary empty factory plus atomic addMany.

RX-2002 `addons/positions/index.ts` exports only selected occurrence/optional original-span capture. Its private `store.ts` stages immutable value-aware term/position roots without display source. `phrases.ts`/`verifier.ts` intersect ordered occurrences and remain separable from utility imports. `addons/phrases/mixed.ts` dispatches explicitly selected per-field source/position strategies; no core import or ordinary facade method is added.

RX-2003 `addons/filters/` supplies typed numeric/set metadata predicates with no lexical groups or side index; `addons/facets/` counts all qualifying metadata before pagination and projects a bounded exact bucket subset. `addons/metadata/payload.ts` privately owns first-party bounded payload/output JSON and resumable Unicode checks. It never enters core imports. The generic `core/capabilities/capture.ts` enforces trusted reported finite capture bounds; `refinement.ts` prepares all requested roles and meters every cursor under one per-registration/search budget. Metadata handles receive immutable schema/payload/revision and current metadata, with no owner/root/scorer. Facets allocate counters only when requested; ordinary result/facade shapes stay unchanged.

RX-2004 addons/inspector provides selected actual native trace projections and bounded JSON diagnostics. core/capabilities coordinates admission-time selection plus resumable preparation/output under existing budgets; trace collection is conditional on an explicit request. The optional module owns source lookup/deep output/schema serialization and installs no participant root. It imports no DOM/persistence/phrase verifier. Normal methods/result shape remain unchanged; evidence is requested under result extensions.
