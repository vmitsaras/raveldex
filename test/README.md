# Verification layers

`tooling/` checks roadmap validation/status and tracking synchronization. `core/` checks input/analysis, import isolation, frequency construction, exact membership, full typed query/BM25 evaluation, numeric facts and invariant corruption. Hand-authored `fixtures/analysis/` contains independently stated terms and original UTF-16 spans; `fixtures/corpora/` adds readable exact-membership expectations and fixed-seed admitted records. `oracle/exact.mjs` scans fixture source with the normative original-token regex and has no production imports. `types/` checks readonly declarations and forbidden/coerced inputs. `npm test` builds ESM then runs all behavior tests; `npm run typecheck` also checks the type fixtures. Internal core passes are supplemented by `consumer/` packed-public-package verification in RX-1006.

After `npm run build`, run `node test/measurements/index-construction.mjs` for reproducible 100/1,000/10,000-record work/structure diagnostics. It verifies invariants and complete common-term membership and prints JSON. Those counts exclude caller source/staging/harness costs and do not measure retained/peak heap bytes or latency. The recorded RX-1002 output lives in `docs/evidence/RX-1002-counts.json`.

`oracle/query.mjs` independently scans source tokens/field statistics and evaluates Boolean participation and weighted BM25; it imports no production module. `fixtures/ranking/` supplies hand numeric constants, explicit membership cases and reproducible generated ASTs/corpora. `query-oracle.test.mjs` checks 958 full-result/numerical comparisons across three seeds and insertion histories. `query-ranking.test.mjs` checks trace replay/allocation paths, exact caps, work and deterministic pagination.

After building, `node test/measurements/query-work.mjs` reproduces the 100/1,000/10,000-record operation counts in `docs/evidence/RX-1003-work.json`; each query is checked against source expectations and tracing on/off. Counts are work-v1 diagnostics, not latency or heap measurements. Preserved independent review scripts in `docs/evidence/RX-1003-review-*.mjs` provide separate source/oracle, heap, trace, failure and abandonment probes.

`oracle/mutations.mjs` independently applies ID/revision policies to original fixture records and rebuilds complete reverse/posting/field/corpus state through the source query oracle. `fixtures/mutations/` supplies deterministic cycles and three seeded 160-operation sequences. `mutation-oracle.test.mjs` checks 507 operations, 511 reconstructed states and 18,683 query/page comparisons, plus hand-derived live-statistic BM25 cases. `mutations.test.mjs` checks participant/source publication, shared admission/work bounds, phase faults, every selected abort/abandonment position, revision exhaustion and collision bucket sharing.

After building, `node test/measurements/mutation-copies.mjs` reproduces `docs/evidence/RX-1004-copies.json`. Each 100/1,000/10,000-record replacement analyzes one record/three values and verifies both old/new states against source. Pointer/key-bucket allocations and copied/updated entries are partial logical counters, without byte/heap/latency claims. Preserved `docs/evidence/RX-1004-review-*.mjs` scripts reproduce separate independent reviewer probes.

`fixtures/execution/host.mjs` provides observable deterministic task/time and structural-signal handles. `execution-lifecycle.test.mjs` tests FIFO/start-time revisions, queue caps, captured data/options, silent/event aborts, deadline/work/stop priority, participant unwind, reentrant final signal reads, honest committed outcomes, disposal and later recovery. `execution-parity.test.mjs` compares 360 complete source-oracle query/pages and 20 full states at four yield quanta; it cancels every selected search/replacement yield and observes real host timers during complete work.

After building, `node test/measurements/execution-work.mjs` reproduces deterministic counters and fresh one-host timing observations for `docs/evidence/RX-1005-work.json`. It checks independent query outcomes, counts host bursts/checks through 10,000 records and observes pending timers/listeners/root identity after cancellation. Physical timing values may vary; unit counts do not bound primitive execution or physical response. Preserved `docs/evidence/RX-1005-review-*.mjs` are independent review programs.

`consumer/` typechecks DOM-free public imports and readonly/negative fixtures after offline local-tarball installation. It verifies exact real-source section extraction/hashes and failed corpus generation, 42 complete query/score comparisons and eight writes/no-ops in both packed and minified runs, navigation links, public method isolation, typed errors, hand arithmetic and cancellation/recovery. `npm run pilot:core` records the 34-section corpus, 19 authored valid judgments, package identities, full bundle graph/gzip settings, guarded startup and raw smoke timings; relevance misses remain visible. Future task slices add source/positional parity, additional capability consumers, worker/transport integration, and qualified UI/browser/AT/resource observations. Consult [the verification plan](../docs/planning/VERIFICATION_PLAN.md).

Record unsupported or unavailable observations as Blocked/Not Applicable with reasons, never as passed. Never make the oracle share the implementation under test for the behavior being checked.

RX-2006 `ui/` installs the actual tarball offline and bundles exported UI/capabilities into browser scenarios. Native submit/facets/paging, focus, debounce/synthetic composition, cancellation versus delayed actual results, revision conflicts, literal unsafe text/marks, typed retry, Inspector, duplicate/destroy/reinitialize, 320px and reduced-motion checks run with pinned Playwright Core and axe-core. `consumer/ui-pilot.test.mjs` separately compares real documentation scores/pages with the independent source oracle and observes source/position phrase parity, Inspector, intercepted native navigation and rapid owner rebuilds. UI public types compile in an isolated DOM project; existing core consumer types remain DOM-free. `npm run check` includes every browser test in a separate bounded phase after the package checks. Local Chrome is the default; CI explicitly installs pinned Chromium and sets `RAVELDEX_UI_BROWSER=chromium`. Browser/axe versions and raw incomplete outcomes are recorded. Synthetic composition is not an OS IME observation, and automated accessibility is not a screen-reader pass.

`addons/phrases/` verifies source adjacency, repeated tokens, native normalization, Boolean participation, full totals/pages/scores, registration/provider failures, transactional source retention and lifecycle. `oracle/phrases.mjs` is independent of production; `fixtures/phrases/verify.mjs` checks literal/generated expectations separately. Run `npm run test:phrases`; after build, `node test/measurements/phrase-work.mjs` measures 100/1,000/10,000-record logical source/work counts and `node test/measurements/phrase-package.mjs` installs an offline tarball and measures complete core/source/combined graphs. Packed/minified runs compare real documentation phrase results and source writes with the independent oracle; browser/worker/heap qualification stays deferred.

RX-2002 `addons/positions/` compares complete source/position/mixed Boolean results, scores and pages with the independent source oracle, checks hand-stated original positions/spans and storage exclusion, and exercises real atomic rollback/stops/clear/disposal. Run `npm run test:positions`. After building, `node test/measurements/position-work.mjs` records four selected representations at 100/1,000/10,000 records; `node test/measurements/position-package.mjs` verifies packed/minified public consumers and complete import graphs. Logical counts are distinct from unmeasured heap and physical latency.

RX-2003 `addons/filters/` independently evaluates typed scalar/range/set leaves and lowers their truth into the independent lexical/BM25 source reference; `addons/facets/` full scans qualified source metadata for exact bucket tables before pages, own selections, typed/null/missing/multi-value rules and bounds. Both verify actual writes, owned FIFO data, shared caps and exhaustive selected cancellation recovery. Run `npm run test:filters` and `npm run test:facets`. After building, `node test/measurements/filter-facet-work.mjs` records logical work at 100/1,000/10,000 records and `node test/measurements/filter-facet-package.mjs` checks installed/minified public combinations and complete graphs. The 15 KiB planning target remains unchanged; a measured miss is recorded honestly per RX-1006-AC05, separate from behavioral acceptance.

RX-2004 addons/inspector verifies hand-derived field/group arithmetic, failed Boolean/filter/phrase paths, off-page/absent IDs, ordinary collector guards, malformed ownership/JSON and explicit source privacy, independent output caps, actual writes and every selected suspension cancellation recovery. Run npm run test:inspector. After build, node test/measurements/inspector-work.mjs observes logical work/no-root state at 100/1,000/10,000 documents; node test/measurements/inspector-package.mjs installs the actual offline tarball, typechecks readonly public types and verifies 27 complete source-oracle comparisons/108 selected documents per packed/minified run plus full graphs/startup/private exclusions. These measurements do not establish physical heap, latency or cross-host qualification.

RX-2005 addons/evidence checks independent literal Unicode/original coordinates, complete source/offset/mixed occurrence parity, actual successful Boolean/phrase participation, safe exact-source slices, grapheme boundaries and truthful window/mark/oversized-match omissions. Admission/provider/limit/failure/lifecycle cases exercise the real FIFO engine and selected cancellation recovery. Run `npm run test:evidence`. After build, `node test/measurements/evidence-work.mjs` saves logical work/selected retention through 10,000 documents; `node test/measurements/evidence-package.mjs` verifies offline public declarations, real documentation ranges/snippets against an independent source regex/Boolean/adjacency oracle, packed/minified parity and full graph/startup/private-export boundaries. Segmentation observations qualify one local host, not every browser/Unicode version or assistive technology.

`adapters/worker/` installs a real tarball, bundles public client and worker entries, and compares direct operations with an actual browser module worker. It separately injects transport failures and inspects mutation receipts and lifecycle cleanup. `npm run test:worker` runs this standalone bounded browser phase after build; `npm test` serializes it after the existing UI browser phase. Browser/transport observations do not establish peak-copy memory, heap or cross-browser portability.
