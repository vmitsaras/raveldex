# Verification layers

`tooling/` checks roadmap validation/status and tracking synchronization. `core/` checks input/analysis, import isolation, frequency construction, exact membership, full typed query/BM25 evaluation, numeric facts and invariant corruption. Hand-authored `fixtures/analysis/` contains independently stated terms and original UTF-16 spans; `fixtures/corpora/` adds readable exact-membership expectations and fixed-seed admitted records. `oracle/exact.mjs` scans fixture source with the normative original-token regex and has no production imports. `types/` checks readonly declarations and forbidden/coerced inputs. `npm test` builds ESM then runs all behavior tests; `npm run typecheck` also checks the type fixtures. Internal core passes are supplemented by `consumer/` packed-public-package verification in RX-1006.

After `npm run build`, run `node test/measurements/index-construction.mjs` for reproducible 100/1,000/10,000-record work/structure diagnostics. It verifies invariants and complete common-term membership and prints JSON. Those counts exclude caller source/staging/harness costs and do not measure retained/peak heap bytes or latency. The recorded RX-1002 output lives in `docs/evidence/RX-1002-counts.json`.

`oracle/query.mjs` independently scans source tokens/field statistics and evaluates Boolean participation and weighted BM25; it imports no production module. `fixtures/ranking/` supplies hand numeric constants, explicit membership cases and reproducible generated ASTs/corpora. `query-oracle.test.mjs` checks 958 full-result/numerical comparisons across three seeds and insertion histories. `query-ranking.test.mjs` checks trace replay/allocation paths, exact caps, work and deterministic pagination.

After building, `node test/measurements/query-work.mjs` reproduces the 100/1,000/10,000-record operation counts in `docs/evidence/RX-1003-work.json`; each query is checked against source expectations and tracing on/off. Counts are work-v1 diagnostics, not latency or heap measurements. Preserved independent review scripts in `docs/evidence/RX-1003-review-*.mjs` provide separate source/oracle, heap, trace, failure and abandonment probes.

`oracle/mutations.mjs` independently applies ID/revision policies to original fixture records and rebuilds complete reverse/posting/field/corpus state through the source query oracle. `fixtures/mutations/` supplies deterministic cycles and three seeded 160-operation sequences. `mutation-oracle.test.mjs` checks 507 operations, 511 reconstructed states and 18,683 query/page comparisons, plus hand-derived live-statistic BM25 cases. `mutations.test.mjs` checks participant/source publication, shared admission/work bounds, phase faults, every selected abort/abandonment position, revision exhaustion and collision bucket sharing.

After building, `node test/measurements/mutation-copies.mjs` reproduces `docs/evidence/RX-1004-copies.json`. Each 100/1,000/10,000-record replacement analyzes one record/three values and verifies both old/new states against source. Pointer/key-bucket allocations and copied/updated entries are partial logical counters, without byte/heap/latency claims. Preserved `docs/evidence/RX-1004-review-*.mjs` scripts reproduce separate independent reviewer probes.

`fixtures/execution/host.mjs` provides observable deterministic task/time and structural-signal handles. `execution-lifecycle.test.mjs` tests FIFO/start-time revisions, queue caps, captured data/options, silent/event aborts, deadline/work/stop priority, participant unwind, reentrant final signal reads, honest committed outcomes, disposal and later recovery. `execution-parity.test.mjs` compares 360 complete source-oracle query/pages and 20 full states at four yield quanta; it cancels every selected search/replacement yield and observes real host timers during complete work.

After building, `node test/measurements/execution-work.mjs` reproduces deterministic counters and fresh one-host timing observations for `docs/evidence/RX-1005-work.json`. It checks independent query outcomes, counts host bursts/checks through 10,000 records and observes pending timers/listeners/root identity after cancellation. Physical timing values may vary; unit counts do not bound primitive execution or physical response. Preserved `docs/evidence/RX-1005-review-*.mjs` are independent review programs.

`consumer/` typechecks DOM-free public imports and readonly/negative fixtures after offline local-tarball installation. It verifies exact real-source section extraction/hashes and failed corpus generation, 42 complete query/score comparisons and eight writes/no-ops in both packed and minified runs, navigation links, public method isolation, typed errors, hand arithmetic and cancellation/recovery. `npm run pilot:core` records the 34-section corpus, 19 authored valid judgments, package identities, full bundle graph/gzip settings, guarded startup and raw smoke timings; relevance misses remain visible. Future task slices add source/positional parity, additional capability consumers, worker/transport integration, and qualified UI/browser/AT/resource observations. Consult [the verification plan](../docs/planning/VERIFICATION_PLAN.md).

Record unsupported or unavailable observations as Blocked/Not Applicable with reasons, never as passed. Never make the oracle share the implementation under test for the behavior being checked.
