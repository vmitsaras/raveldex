Site sources and local browser commands are documented in [site/README.md](site/README.md); N6 evidence records distinguish automated checks from unrun human AT/physical-input/zoom and deployment work.

- Native TypeScript, pure ESM, framework-agnostic core with no runtime dependencies or foreign engine below it.
- Core owns indexing, retrieval, native BM25, exact totals, deterministic order, atomic incremental writes, FIFO execution, finite limits and cooperative cancellation.
- Core alone retains no original text, positions, offsets, DOM, worker or database state. Optional registrations/providers are explicit at owner creation.
- Source, phrases, positions/offsets, filters/facets, Inspector, evidence/snippets and UI/CSS stay optional. The UI borrows the application engine and display records; destroy UI before disposing its owner.
- Workers own one complete engine. Transport loss can leave outcomes unknown; receipts/reconciliation and authoritative source recovery remain explicit.
- Source snapshots rebuild under the receiver. Native snapshots require exact application-qualified Node environments; browser/worker native portability is unavailable.
- English is also packaged independently. The separate Astro adapter builds explicit static allowlists and loads artifacts on demand; it adds no framework dependency to core.

The [API index](docs/api/README.md), [compatibility policy](docs/release/COMPATIBILITY.md), specifications and current source define exact public behavior.
