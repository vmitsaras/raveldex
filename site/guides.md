# Guides

New to Raveldex? [Getting started](../docs/api/GETTING_STARTED.md) takes you from installation to your first search. If you already have an index, choose the task you want to work on below.

| Task | Guide |
| --- | --- |
| Define searchable fields, add records and read results | [Core usage](../docs/api/CORE.md) |
| Search phrases, filter records or count facets | [Search add-ons](../docs/api/ADDONS.md) |
| Add a browser search form | [Native UI and CSS](../docs/api/HOSTS.md#native-dom-ui-and-css) |
| Run search in a module worker | [Worker setup](../docs/api/HOSTS.md#one-owner-module-worker) |
| Save, restore or erase a collection | [Snapshots and storage](../docs/api/HOSTS.md#source-and-native-snapshots) |
| Add search to static Astro pages | [Astro integration](../docs/api/STATIC_ASTRO.md) |
| Select an analyzer | [English](../docs/api/ENGLISH.md) or [code identifiers](../docs/api/IDENTIFIERS.md) |
| Build a richer search box | [Typo tolerance](../docs/api/TYPO.md), [suggestions](../docs/api/SUGGESTIONS.md), [synonyms](../docs/api/SYNONYMS.md), [query syntax](../docs/api/QUERY_SYNTAX.md) |
| Check host requirements and recover failures | [Compatibility](../docs/api/COMPATIBILITY.md) and [practical limits](../docs/api/LIMITATIONS.md) |
