Data and capabilities

Every starter indexes an explicit allowlist of public records. None crawls a site or adds a remote search service. Keep private content out of public assets and deploy rebuilt pages and search files together.

Browser inline, dropdown, directory and rich results load at page initialization. Astro inline and directory wait for Enable; documentation modals load their complete local index on first open. All eight projects use the main thread. Workers are a separate integration.

Requirements stay with the example: inline snippets and topics, modal sections and dialog, dropdown Popover and full results, directory filters and Astro artifacts, and rich result metadata and images.

Keyboard and cleanup

Keep ordinary result links and visible keyboard focus. Inline and modal append matches with Load more; the dropdown uses Arrow keys, Enter and Escape; directories use native filters and complete result pages. The application owns its engine; destroy the borrowed view before disposing that owner.

Follow the Browser starter instructions for loading/Retry, no-results recovery and cleanup: Inline, Modal, Dropdown, Directory, and rich results. See starter adoption and local checks for the shared contract and manual browser/assistive technology checks.

A small working example

After installing core, save this as search.mjs and run node search.mjs. It adds one document and searches for atomic.

View the complete core example
import { createRaveldex } from '@vmitsaras/raveldex';

const engine = createRaveldex({
  schema: { text: { title: { boost: 2 }, body: {} } },
});
try {
  await engine.add({
    id: 'guide:updates',
    text: { title: 'Atomic updates', body: 'Replace one complete record.' },
  });
  const page = await engine.search('atomic');
  console.log(page.revision, page.total, page.hits);
} finally {
  await engine.dispose();
}

You should see revision 1, a total of 1 and one hit with ID guide:updates. Look up that ID in your application to get its title and URL. The example disposes the engine when it finishes.
