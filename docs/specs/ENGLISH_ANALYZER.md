# Evaluated English analyzer — RX-A040

Status: adopted for the owner's explicit English/existing Raveldex documentation selection on October 29, 2026. Language selection preceded implementation. Other optional tasks and publication remain separate.

## Need and bounded policy

The real input corpus is the existing frozen 34-section English Raveldex documentation (`test/fixtures/relevance/corpus.json`). Recorded lexical evaluation misses include word-form differences. The separately frozen English title-navigation fixture supplies judged singular/plural/participle intents; it is not a replacement for the original 76 judgments. The public contract is [English morphology](../api/ENGLISH.md).

`english-porter1980-v1` means original basic-v1 segmentation/NFKC/lowercase followed by original-paper Porter 1980 on ASCII a–z terms longer than two characters. Pin the algorithm's original ABLI and OU rules and generic doubled-consonant predicate; no later BLI/LOGI extension or Porter2 update is permitted under this ID. The [primary definition](https://snowballstem.org/algorithms/porter/stemmer.html) is algorithm provenance; this repository supplies a fresh native implementation, not a foreign runtime dependency. Non-ASCII/digit-containing terms pass unchanged. Keep every stop word, one output per original token, dense positions, positionLength 1, exact original full-token UTF-16 spans and independent array/value boundaries.

No imported pack can select itself. `Configuration.analyzer` explicitly chooses the descriptor and its corresponding installed `analyzer:<id>` provider. The default remains basic-v1 with identical ordinary behavior. A pack is an exclusive trusted `analyzer` role with a captured `single-token-transform` handle, immutable identity and `indexEffect: analysis`; no live retrofit, source/position participant or codec is created. Core owns segmentation/coordinates and validates finite, nonempty, well-formed canonical transformed terms. It never retokenizes/restems canonical output. The new role supports only one-to-one morphology, not arbitrary token/phrase graphs or stop-word holes.

Index writes, raw query analysis, source/position phrase construction/verification, original evidence/snippet checks and snapshot source/native verification share one selected operation runner. A module budget is shared across tokens, values and providers; restore source records reuse a single runner. Every yielded transformation step joins existing core operation charging/stops. The private initial-construction fixture still rejects all add-ons and is not an English public indexing API. Existing v1 weighted expansion stays basic-only; requests fail explicitly under English rather than silently using basic-specific tables. Metadata remains untransformed.

The analyzer changes dictionary groups, native TF/DF/statistics and therefore scores. Phrase equivalence is equality of adjacent analyzed terms, not original literal spellings. Prefix requests analyze once and expand prefixes of stems with ordinary complete bounds. Original spans are never shortened to stem lengths. Snapshot/worker compatibility must bind the actual selected descriptor and canonical capability manifests, preserving exact Node qualification and rejecting mismatches/unknown implementations. Source rebuild is not implicit cross-language migration.

An independent English-reading evaluator/oracle checks algorithm variants, segmentation, source spans, phrase boundaries, coalesced DF/TF/BM25, all core Boolean membership and bounded pages. State clearly whether review is AI or human.
2. Exercise selected and registered-but-unselected configurations, missing/malformed/incompatible packs, owned handles, invalid transform output, narrowed shared/module budgets, cancellation at every observed suspension, queue ownership, atomic mutations, deadline and disposal.
3. Preserve all original 76 basic-mode judgments with the pack installed but unselected. Report separate selected-English metrics with natural-language/overstemming failures visible; do not promise all queries improve. The new frozen zero-false-positive aspiration may fail without changing the fixed standard algorithm, and must be reported as a relevance limitation.
4. Verify source/positions/mixed phrases and original evidence/snippets. Run installed/minified direct and actual worker queries, source worker restore/reconciliation, explicit qualified Node source/native round trips, and mismatched analyzer/version/profile/manifests. No probe or declaration proves universal Unicode portability.
5. Measure core versus language-only/combined import graphs and constant/optional state separately from logical operation work. Language implementation/tables must stay outside the core graph; generic selection code has its own measured core cost. No heap/allocation/physical-copy or manual-AT claim follows from these counters and package checks.

The finite technical English corpus and one AI evaluator do not establish language-wide linguistic correctness or native-human usability review. No stop-word dictionaries, irregular lemmatization, accent folding, other language, code/identifier analyzer, UI integration or further N5 feature is part of this slice.
