Examples

For a complete interface to copy into your application, choose inline search, a documentation search modal, or compact header search. Inline and modal have browser and Astro projects; the header starter is a plain-browser project. Each includes explicit content, controls, styles and cleanup. The browser demo below is also available for exploring query and execution details.

Use inline search for a field and results that stay in the page; use the modal for search opened from a button. The compact header offers a few page links and a complete inline results route. All three galleries include a working installed preview, complete source downloads and an edit/build/preview CSS walkthrough. The current packages are private and unpublished, so each setup guide uses supplied matching local tarballs.

Repository commands need a source checkout, repository access, Node 24 and an initial npm ci. If you only have package tarballs, follow installation and use the copied API recipes instead.

The five starters index explicit public records rather than crawling pages. The header uses core-only title/link results and native Popover; its optional larger-search button also needs native dialog. Snippets and section previews in the inline/documentation-modal projects need Intl.Segmenter; their section/static asset verification needs Web Crypto over HTTPS or localhost. Each guide explains its selected capabilities and how to replace the sample data. Review starter adoption and local checks before changing those capabilities or claiming support for your target browsers and assistive technology.

Each walkthrough explains what you should see and how to clean up. Stop ordinary preview servers with Ctrl+C. The Astro example uses its documented project-scoped stop command.
