# Documentation search for a browser site

Copy this complete starter to add a native documentation modal with real page results and anchored section previews. The six workshop pages are an explicit allowlist; the same authored section content builds the index, original UTF-16 ranges and real heading IDs. Nothing crawls or extracts HTML. Ordinary browse links work before search loads and without JavaScript.

## Install, build and preview

Use Node 22 or later and npm. Extract the complete starter into an empty directory with `tar -xzf modal-browser.tar.gz --strip-components=1`, then enter that directory. From a source checkout, you can instead copy the complete `examples/modal-browser/` folder to a new project.

Install Raveldex and the starter's pinned build tooling, then build and preview:

```sh
npm install @vmitsaras/raveldex@1.0.0
npm run build
npm run preview -- --port 4177
```

Keep the generated `package-lock.json` and use `npm ci` for subsequent installs. To test a local Raveldex build, substitute its core tarball path for the package name in the install command.

Open `http://127.0.0.1:4177/`. Choose **Search documentation**, then search `bobbin`. The sewing page has one matching **Thread the machine** section preview; following that link opens its actual `threading-100%` heading. Search `workshop` for all six matching pages, with three initially displayed; **Load more** reveals the next batch. The Topic filter narrows matching pages. Close with Escape or **Close search**, then reopen to check the preserved words/filter. Some browsers clear a focused search field on the first Escape; press Escape again or use **Close search** to dismiss. Ctrl+C stops this preview.

## Deploy below a path

Stop the preview and use the same base when rebuilding and serving:

```sh
RAVELDEX_MODAL_BASE=/help/ npm run build
RAVELDEX_MODAL_BASE=/help/ npm run preview -- --port 4177
```

Open `http://127.0.0.1:4177/help/`. Deploy the complete new `dist/` together under that base. Scripts, CSS, data, browse links, result pages and anchors use the same base. Rebuild whenever it changes. The preview is an HTTP server, so do not open HTML using `file:`.

## Replace the pages and sections

Edit `content.json` and rebuild. Each entry has a unique nonempty `id`, a plain `title`, string `category`, unique `/guide/slug/` path, and one to 64 explicit sections. Titles must contain non-whitespace text, be well-formed UTF-16 and fit within 1,024 UTF-16 units. A section supplies its exact raw HTML `anchor`, plain non-whitespace `heading` and original `body`. Valid surrounding title/heading whitespace is preserved. Percent signs and `#` characters in anchors are literal; the result link URL-encodes them exactly once. Do not pre-encode or slugify the anchor. Keep IDs stable and paths unique. This starter accepts 1–1,000 explicit pages and indexes batches of 100; these bounds are not performance guarantees. Do not put private material in public artifacts.

`content.mjs` creates one original body string per page: heading, newline, section body, then two newlines before the next section. Its section map uses half-open original UTF-16 offsets in that exact string. `build.mjs` renders the matching heading IDs. `load.mjs` indexes one record per page and binds maps to that receiving engine's successful mutation revision. Native totals, scores, ordering and filters continue to count pages; previews are bounded context, not a global count of matching sections. If you render existing pages yourself, retain these relationships and supply their real canonical URLs and exact original source ranges. The UI does not inspect target pages for you.

The explicit optional registrations are `createSourceProvider({ fields: ['body'] })`, `createSectionEvidence({ fields: { body: 'source' } })` and `createFacets({ fields: ['category'] })`. Title and body are searched, with title boosted by two. Source-based section evidence retains original body text. Sections and ordinary `snippetFields` are mutually exclusive. Remove section maps/evidence together to use plain title/link results, and remove facet UI/metadata/registration together when no Topic filter is needed.

The build compiles the SHA-256 of the exact `content.json` bytes into the client. On first open, the loader checks fetched bytes before creating an engine, so changed/stale/mixed content fails visibly instead of silently pointing at different sections. Deploy matching HTML, bundle, CSS, data and rendered targets together; the digest does not authenticate a publisher or prove that separately deployed pages have the promised IDs. Rebuild after editing data. The complete data file is loaded once and used to create a full local index; this is not a lazy or sharded index. There is no worker, server search, persistence or telemetry.

## Change a few CSS values

`main.mjs` explicitly imports the package's `modal.css` (including shared inline CSS), then `theme.css`. Change scoped public properties and rebuild:

```css
.raveldex-modal {

  --raveldex-modal-radius: .8rem;
}
.raveldex-inline {
  --raveldex-inline-accent: #294e82;
  --raveldex-inline-gap: 1rem;
}
```

The modal properties control the surface/layout; inline properties control shared results/controls. Keep contrast and visible focus usable. `controller.mjs` sets labels, batch size and `resetOnClose`; setting `resetOnClose: true` clears words and filters on close. The default is preservation with a fresh native query when reopened. No global keyboard shortcut is installed by this application wrapper. Direct public modal integrations can explicitly opt into coordinated shortcuts.

## First-open loading, retry and disposal

`main.mjs` creates a controller without fetching data or creating an engine. The first trigger activation opens an immediate native loading dialog with **Cancel loading search**. It then fetches and verifies the data and transfers one newly created owner to the modal. Repeated opens share the current initialization. Cancel/Escape/native close abort the attempt; a late owner is disposed and cannot reopen the abandoned UI. Reopening while an old attempt unwinds creates a new current attempt; old finalizers cannot clear it. On failure, **Retry loading search** starts a fresh attempt. Try blocking `content.json`, open search, then unblock and Retry. Browse links remain available after closing the loading dialog.

`createDocumentationSearch({ root, trigger, loadingDialog, status, retry, load, resetOnClose })` returns `open()`, `close()` and `destroy()`. `load(signal)` must transfer a **newly owned** `{ engine, documents, pageSections, dispose }`. This controller disposes that owner on initialization failure, late completion or destruction. Do not return a borrowed application engine. To integrate an engine owned elsewhere, use `mountRaveldexModal` directly and destroy that UI before the existing owner disposes its engine.

Closing an initialized modal keeps its engine and current words/filter values; it cancels presentation work and revalidates on reopen. `destroy()` is idempotent, returns one stable promise, removes loading/retry/trigger listeners, aborts initialization, destroys the borrowed modal before disposing its owned engine, and waits for late owners to be released. Call and await it before replacing the host in a client navigation system. `pagehide` destroys this page's controller; a persisted `pageshow` creates a fresh, closed controller for a back/forward-cache restore. Native dialog support, `Intl.Segmenter` and Web Crypto in a secure context (localhost or HTTPS) are required. Failures leave the complete browse route intact.

Installed headless tests exercise copied files, real package bytes, base changes, anchors, loading failure/retry and lifecycle races. Human screen-reader, physical input/on-screen keyboard, actual zoom, broad browser/device and large-data performance qualification remain separate.

    status: document.querySelector('[data-search-status]'), retry: document.querySelector('[data-search-retry]'),

window.addEventListener('pagehide', () => {
  navigationEpoch++; trigger.hidden = true;
  if (search) { stopped = search.destroy(); search = undefined; }
});
window.addEventListener('pageshow', event => {
  if (!event.persisted) return;
  const epoch = ++navigationEpoch;
  void stopped.then(() => { if (epoch === navigationEpoch) initialize(); });

controller.mjs

import { mountRaveldexModal } from '@vmitsaras/raveldex/addons/ui/modal';

// Application-owned first-open loading. The public UI only borrows an engine.
// load(signal) transfers a NEW owner {engine, documents, pageSections, dispose}.
export function createDocumentationSearch({ root, trigger, loadingDialog, status, retry, load, resetOnClose = false }) {
  const doc = root.ownerDocument, cancel = loadingDialog.querySelector('[data-search-cancel]');
  let owner, ui, current, loadingOpener, ended = false, wanted = false, disposal;
  const jobs = new Set();
  function connected() { return root.isConnected && trigger.isConnected && loadingDialog.isConnected && root.ownerDocument === doc && trigger.ownerDocument === doc && loadingDialog.ownerDocument === doc; }
  function say(text) { status.textContent = text; }
  function hideLoading(opener) {
    const hadFocus = loadingDialog.contains(doc.activeElement);
    if (loadingDialog.open) loadingDialog.close();
    // WebKit may leave focus in the closed loading shell. Restore only our
    // transition; authored callbacks or another modal retain their own focus.
    const active = doc.activeElement;
    if (hadFocus && opener?.isConnected && opener.ownerDocument === doc &&
      (active === doc.body || active === opener || loadingDialog.contains(active)) &&
      !doc.querySelector('dialog:modal')) opener.focus({ preventScroll: true });
  }
  function close() {
    wanted = false;
    const prior = current; current = undefined;
    // Invalidate before abort/focus callbacks can reenter this controller.
    prior?.abort.abort();
    if (current || wanted) return; // An abort listener opened a newer session.
    ui?.close();
    if (!current && !wanted) hideLoading(prior?.opener ?? loadingOpener);
  }
  function open(fromTrigger = false) {
    if (ended || !connected() || trigger.disabled) return Promise.resolve();
    if (ui) { ui.open(); return Promise.resolve(); }
    // Native close() changes modality before its queued close event arrives.
    if (current && !loadingDialog.open) close();
    if (ended || !connected() || trigger.disabled) return Promise.resolve();
    if (current) return current.promise;
    if (doc.querySelector('dialog:modal') && !loadingDialog.open) return Promise.resolve();
    wanted = true;
    const focused = doc.activeElement;
    const attempt = { abort: new AbortController(), opener: fromTrigger ? trigger
      : loadingDialog.contains(focused) ? loadingOpener ?? trigger
        : focused && focused !== doc.body ? focused : trigger };
    loadingOpener = attempt.opener;
    let finish;
    attempt.promise = new Promise(resolve => { finish = resolve; });
    current = attempt; jobs.add(attempt.promise);
    const currentActive = () => !ended && wanted && current === attempt && connected() && !attempt.abort.signal.aborted;
    const active = () => currentActive() && loadingDialog.open;
    const finishEarly = () => { jobs.delete(attempt.promise); finish(); return attempt.promise; };
    retry.hidden = true; say('Loading search. You can cancel and browse the guides.');
    // Replacing authored status children can synchronously close/destroy/reopen.
    if (!currentActive()) return finishEarly();
    try {
      if (!loadingDialog.open) loadingDialog.showModal();
      if (active()) cancel.focus({ preventScroll: true });
    } catch {
      if (current === attempt) {
        current = undefined; wanted = false;
        if (!ended) say('Search could not open. Browse the guides below.');
      }
      return finishEarly();
    }
    void (async () => {
      let candidate, mounted;
      try {
        if (!active()) return;
        candidate = await load(attempt.abort.signal);
        if (!active()) return;
        hideLoading(attempt.opener);
        if (ended || !wanted || current !== attempt || !connected()) return;
        // Native close restores the real pre-loading opener. Respect focus
        // callbacks that abandon the session before mounting its replacement.
        mounted = mountRaveldexModal({ root, trigger, engine: candidate.engine, documents: candidate.documents,
          pageSections: candidate.pageSections, pageSize: 3,
          facets: [{ field: 'category', label: 'Topic' }], resetOnClose,
          messages: { label: 'Search the workshop guide', placeholder: 'Try bobbin or workshop',
            idle: 'Search the workshop guide, then choose a topic to narrow the results.',
            facetSummary: 'Topics: {total} · Not shown: {omitted}' },
          modalMessages: { title: 'Search workshop documentation' } });
        if (ended || !wanted || current !== attempt || !connected()) return;
        owner = candidate; candidate = undefined; ui = mounted; mounted = undefined;
        current = undefined;
        ui.open();
      } catch {
        if (currentActive()) {
          if (!loadingDialog.open && !doc.querySelector('dialog:modal')) loadingDialog.showModal();
          if (active()) {
            say('Search could not load. Retry or close to browse the guides.');
            if (active()) retry.hidden = false;
          }
        }
      } finally {
        mounted?.destroy();
        try { if (candidate) await candidate.dispose(); }
        finally {
          if (current === attempt) current = undefined;
          jobs.delete(attempt.promise); finish();
        }
      }
    })().catch(() => { /* The owner's cleanup was attempted; no abandoned UI can mount. */ });
    return attempt.promise;
  }
  function onTrigger() { if (!ui) void open(true); }
  function onCancel(event) { event.preventDefault(); close(); }
  function onNativeClose() { if (!loadingDialog.open && !ui) close(); }
  function onRetry() { void open(); }
  trigger.addEventListener('click', onTrigger); cancel.addEventListener('click', close);
  loadingDialog.addEventListener('cancel', onCancel); loadingDialog.addEventListener('close', onNativeClose);
  retry.addEventListener('click', onRetry);
  function destroy() {
    if (ended) return disposal;
    ended = true;
    let resolve, reject;
    disposal = new Promise((done, fail) => { resolve = done; reject = fail; });
    const previous = owner, previousUI = ui; owner = undefined; ui = undefined;
    close();
    trigger.removeEventListener('click', onTrigger); cancel.removeEventListener('click', close);
    loadingDialog.removeEventListener('cancel', onCancel); loadingDialog.removeEventListener('close', onNativeClose);
    retry.removeEventListener('click', onRetry);
    previousUI?.destroy(); retry.hidden = true;
    Promise.all([...jobs, Promise.resolve().then(() => previous?.dispose())]).then(resolve, reject);
    return disposal;
  }
  return Object.freeze({ open, close, destroy });
}
load.mjs

import { createRaveldex } from '@vmitsaras/raveldex';
import { createSourceProvider } from '@vmitsaras/raveldex/addons/phrases/source';
import { createSectionEvidence } from '@vmitsaras/raveldex/addons/sections';
import { createFacets } from '@vmitsaras/raveldex/addons/facets';
import { preparePages } from './content.mjs';

export async function loadGuides(contentUrl, expectedSHA256, signal) {
  const response = await fetch(contentUrl, { signal, cache: 'no-cache' });
  if (!response.ok) throw new Error('Guide data is unavailable');
  const bytes = await response.arrayBuffer(); signal.throwIfAborted();
  const digest = [...new Uint8Array(await crypto.subtle.digest('SHA-256', bytes))].map(n => n.toString(16).padStart(2, '0')).join('');
  if (digest !== expectedSHA256) throw new Error('Guide data belongs to a different build');
  const pages = preparePages(JSON.parse(new TextDecoder('utf-8', { fatal: true }).decode(bytes)));
  signal.throwIfAborted();
  const engine = createRaveldex({
    schema: { text: { title: { boost: 2 }, body: {} }, metadata: { category: { type: 'string' } } },
    addons: [createSourceProvider({ fields: ['body'] }), createSectionEvidence({ fields: { body: 'source' } }),
      createFacets({ fields: ['category'] })],
  });
  try {
    let mutation;
    for (let offset = 0; offset < pages.length; offset += 100) {
      mutation = await engine.addMany(pages.slice(offset, offset + 100).map(page => ({ id: page.id,
        text: { title: page.title, body: page.body }, metadata: { category: page.category } })), { signal });
    }
    signal.throwIfAborted();
    const base = new URL('./', contentUrl);
    return { engine, documents: pages.map(page => ({ id: page.id, title: page.title, url: new URL(page.path.slice(1), base).href })),
      pageSections: { kind: 'raveldex-page-sections', version: 1, revision: mutation.revision,
        pages: pages.map(page => ({ pageId: page.id, sections: page.maps })) }, dispose: () => engine.dispose() };
  } catch (error) { await engine.dispose(); throw error; }
}

// This explicit allowlist is also the source used to render real anchor targets.
export function preparePages(entries) {
  if (!Array.isArray(entries) || entries.length === 0 || entries.length > 1000) throw new Error('Expected 1–1000 explicit pages');
  const ids = new Set(), paths = new Set();
  return entries.map(entry => {
    if (!entry || !['id', 'title', 'category', 'path'].every(key => typeof entry[key] === 'string' && entry[key])
      || !entry.title.trim() || entry.title.length > 1024 || !entry.title.isWellFormed()
      || entry.id.length > 256 || ids.has(entry.id) || paths.has(entry.path)
      || !/^\/guide\/[a-z0-9-]+\/$/.test(entry.path) || !Array.isArray(entry.sections)
      || !entry.sections.length || entry.sections.length > 64) throw new Error('Invalid or duplicate page');
    ids.add(entry.id); paths.add(entry.path);
    let body = ''; const anchors = new Set(), sections = [];
    for (const section of entry.sections) {
      if (!section || !['anchor', 'heading', 'body'].every(key => typeof section[key] === 'string' && section[key])
        || !section.heading.trim() || !section.anchor.isWellFormed() || !section.heading.isWellFormed() || !section.body.isWellFormed()
        || section.anchor.length > 256 || section.heading.length > 512 || /[\p{Cc}\s]/u.test(section.anchor)
        || section.anchor.includes(':~:') || anchors.has(section.anchor)) throw new Error('Invalid or duplicate section');
      anchors.add(section.anchor);
      if (body) body += '\n\n';
      const start = body.length; body += section.heading + '\n' + section.body;
      sections.push({ anchor: section.anchor, heading: section.heading, headingLevel: 2,
        field: 'body', valueIndex: 0, start, end: body.length });
    }
    return { ...entry, body, maps: sections };
  });

# Documentation modal starter for Astro

Copy this complete starter to build a workshop guide with optional search in a native dialog. It creates one search record per actual guide page, with evidence-backed links to the page's authored headings. The ordinary guide links work before loading and without JavaScript. Search data loads only when someone selects **Search the guide**.

## Copy and install

Use Node 24 and npm. Extract the complete starter into an empty directory with `tar -xzf modal-astro.tar.gz --strip-components=1`, then enter it. From a source checkout, copy the entire `examples/modal-astro/` folder into a new project instead.

```sh
export RAVELDEX_MODAL_ASTRO="$(pwd -P)"
npm --prefix "$RAVELDEX_MODAL_ASTRO" install @vmitsaras/raveldex@1.0.0 @vmitsaras/raveldex-astro@1.0.0
```

The starter pins Astro `7.3.2`. Keep the generated `package-lock.json` and use `npm ci` afterward. To test local changes, substitute matching core and Astro tarball paths in the install command. Keep `RAVELDEX_MODAL_ASTRO` set for the build and preview commands below.

## Build and preview

```sh
ASTRO_TELEMETRY_DISABLED=1 npm --prefix "$RAVELDEX_MODAL_ASTRO" run build
ASTRO_TELEMETRY_DISABLED=1 npm --prefix "$RAVELDEX_MODAL_ASTRO" run preview -- --host 127.0.0.1 --port 4321
```

Open the HTTP URL Astro prints. Choose another port if occupied; Ctrl+C stops a foreground preview. Astro may start a background server in an agent environment; use `npm --prefix "$RAVELDEX_MODAL_ASTRO" run preview -- stop` to stop that project's background preview before rebuilding. Select **Search the guide**, enter `workshop` and select **Search**. There are six matching pages; three appear first, and **Load more** shows all six. The Topic filter can narrow these pages. Search `bobbin` to find **Sewing machines**, then follow **Wind the bobbin** to the actual heading. That example intentionally includes `%`, `#` and non-ASCII characters in its raw anchor: the URL encodes them once.

The initial loading window has a visible close button and native Escape support. In the ready search window, some browsers clear a focused search field on the first Escape; press Escape again or use **Close search** to dismiss. Closing it cancels initialization. A failed artifact shows **Retry loading search**; guide navigation remains available after closing the window. Block a `/raveldex/` asset locally, open search, unblock it and retry to exercise recovery.

## Deploy under a subdirectory

Stop preview, then rebuild and preview with the same base:

```sh
RAVELDEX_ASTRO_BASE=/help/ ASTRO_TELEMETRY_DISABLED=1 npm --prefix "$RAVELDEX_MODAL_ASTRO" run build
RAVELDEX_ASTRO_BASE=/help/ ASTRO_TELEMETRY_DISABLED=1 npm --prefix "$RAVELDEX_MODAL_ASTRO" run preview -- --host 127.0.0.1 --port 4321
```

Open `http://127.0.0.1:4321/help/` or the actual reported port. Deploy the complete rebuilt `dist/` together. The build, manifest URL, result pages and heading links share the same Astro base. Old HTML mixed with a different build's manifest is refused; source/display/section byte and identity checks refuse mixed assets. Do not change the base without rebuilding.

## Replace pages and sections

Edit `content.json`: choose a new `buildId` when content or configuration changes, then rebuild. Each entry has a unique route-safe `slug`, plain title, string category and explicitly authored sections. Each section has an exact raw `anchor`, a heading and original plain-text `text`. Its anchor must be unique within that page and match the real rendered heading's ID.

`content.mjs` joins section texts with two newlines and calculates their disjoint original UTF-16 ranges. The exact same entries render headings in `src/pages/guide/[slug].astro`, create native records in `astro.config.mjs` and supply the separate optional section maps. Do not normalize or rewrite text after calculating offsets. When integrating existing pages, provide the original indexed field/value text, real URLs/IDs and equivalent ranges yourself. This starter does not crawl routes or extract HTML/Markdown. Never put private content into public artifacts.

`configuration.mjs` explicitly registers all original source fields for static source reconstruction, source-based section evidence and native category facets. `src/search.mjs` loads the source owner, then display records and the source-only section companion through that same handle. The companion validates source/display/build/base identity and stamps the receiving owner's revision; the modal checks it again when searching. `dist/raveldex/` contains the manifest, complete source/display files and separate section files. This is a complete local index loaded on first use, not a sharded or lazy index format.

## Change the appearance and query policy

`src/main.mjs` explicitly imports `modal.css` and then `src/style.css`. Change the scoped public properties in the latter, then rebuild:

```css
.raveldex-inline {
  --raveldex-inline-accent: #563c83;
  --raveldex-inline-focus: #874a00;
}
.raveldex-modal {
  --raveldex-modal-max-width: 46rem;
  --raveldex-modal-radius: .75rem;
}
```

Keep text/focus/highlight contrast usable. The modal uses final-word prefix matching, three pages per batch and at most six rendered pages. Close preserves words and selected Topic by default, clears results, and reruns the first page on reopen. Set `resetOnClose: true` in the options in `src/main.mjs` to clear words and Topic instead. No global shortcut is installed by this loading wrapper. Once you already own a ready engine, the direct public modal supports its coordinated opt-in shortcut.

## Ownership, cancellation and cleanup

`createDocumentationSearch()` returns `open()`, `close()` and `destroy()`. Concurrent opens share the current initialization. Close invalidates that attempt before aborting it. A rapid reopen can start a fresh attempt while an abort-ignoring earlier loader unwinds; old completion cannot mount or reopen search. Each newly returned abandoned handle is disposed. Successful initialization retains its owned handle across closes so controls can preserve their values. There is no automatic network retry or reused partial candidate after failure.

A custom `load` must transfer a **fresh newly owned** `LoadedStaticSearch` handle on every call. The wrapper owns that handle and destroys its borrowed modal before disposing it. Never return an engine or static handle owned elsewhere. To use an existing borrowed application engine, mount `mountRaveldexModal` directly with its documents/maps, destroy only that UI when the view ends, and let the existing owner dispose its engine.

Call and await `destroy()` before replacing this integration. The stable destruction promise waits for late loader handles; listeners are removed, the loading shell closes, the original search fallback is restored and owners are released once. `src/main.mjs` handles `pagehide` and creates a fresh wrapper after teardown on back/forward-cache `pageshow`. The example uses static navigation, without Workbench selectors, global debug state, storage or telemetry.

Automated installed tests cover finite native browser interaction and cleanup. Human screen-reader behavior, physical IME/touch/on-screen keyboard, actual zoom, broader browsers/devices, calibrated memory/latency and hosted deployment require separate qualification.

/** Application-owned initialization, separate from the modal's borrowed engine.
 * A custom load must transfer a fresh LoadedStaticSearch handle on every call.
 * destroy waits for even an abort-ignoring loader's late handle to be disposed. */
export function createDocumentationSearch({ root, trigger, loadingDialog, status, retry,
  manifestUrl, buildId, resetOnClose = false, load = loadStaticSearch }) {
  const document = root.ownerDocument;
  const closeButton = loadingDialog.querySelector('[data-loading-close]');
  const original = { hidden: trigger.hidden, retryHidden: retry.hidden, status: [...status.childNodes] };
  const attempts = new Set();
  let current, owned, ui, loadingOpener, destroyed = false, disposal;
  const connected = () => root.isConnected && trigger.isConnected && loadingDialog.isConnected
    && root.ownerDocument === document && trigger.ownerDocument === document && loadingDialog.ownerDocument === document;
  function restoreFocus(opener, hadFocus) {
    if (hadFocus && opener?.isConnected && opener.ownerDocument === document
      && (document.activeElement === document.body || document.activeElement === opener || loadingDialog.contains(document.activeElement))
      && !document.querySelector('dialog:modal')) opener.focus({ preventScroll: true });
  }
  function hideLoading(opener) {
    const hadFocus = loadingDialog.contains(document.activeElement);
    if (loadingDialog.open) loadingDialog.close();
    restoreFocus(opener, hadFocus);
  }
  function close() {
    if (destroyed) return;
    const attempt = current;
    // Invalidate before abort/native close: both can invoke authored callbacks.
    current = undefined;
    attempt?.abort.abort();
    if (current || destroyed) return;
    if (ui) ui.close();
    else hideLoading(attempt?.opener ?? loadingOpener);
  }
  function open(fromTrigger = false) {
    if (destroyed || !connected()) return Promise.resolve();
    if (ui) { ui.open(); return Promise.resolve(); }
    if (current && loadingDialog.open) return current.promise;
    // A raw native close may precede its queued close event.
    if (current) close();
    if (current) return current.promise;
    if (destroyed || !connected() || document.querySelector('dialog:modal')) return Promise.resolve();
    const focused = document.activeElement;
    const attempt = { abort: new AbortController(), opener: fromTrigger ? trigger
      : loadingDialog.contains(focused) ? loadingOpener ?? trigger
        : focused && focused !== document.body ? focused : trigger };
    current = attempt; loadingOpener = attempt.opener;
    const live = () => !destroyed && current === attempt && !attempt.abort.signal.aborted && connected();
    // Publish the promise before load can run or reenter the controller.
    attempt.promise = Promise.resolve().then(async () => {
      let candidate, mounted, failed = false;
      try {
        if (!live() || !loadingDialog.open) return;
        candidate = await load({ manifestUrl, expectedBuildId: buildId,
          configuration: configuration(), signal: attempt.abort.signal });
        if (!live() || !loadingDialog.open) return;
        const documents = await candidate.loadDocuments({ signal: attempt.abort.signal });
        if (!live() || !loadingDialog.open) return;
        // Explicit source-only companion; it validates this receiving owner's
        // revision against the exact source/display/build identities.
        if (typeof candidate.loadSections !== 'function') throw new Error('Section companion required');
        const pageSections = await candidate.loadSections({ signal: attempt.abort.signal });
        if (!live() || !loadingDialog.open) return;
        mounted = mountRaveldexModal({ root, trigger, engine: candidate.engine, documents, pageSections,
          pageSize: 3, resetOnClose, shortcut: false,
          facets: [{ field: 'category', label: 'Topic' }],
          messages: { label: 'Search the workshop guide', placeholder: 'Try bobbin or booking', clear: 'Clear search and filters',
            idle: 'Search the workshop guide, then choose a topic to narrow the results.',
            facetSummary: 'Topics: {total} · Not shown: {omitted}' },
          modalMessages: { title: 'Search the workshop guide' } });
        if (!live() || !loadingDialog.open) return;
        hideLoading(attempt.opener);
        if (!live()) return;
        ui = mounted; mounted = undefined;
        owned = candidate; candidate = undefined;
        current = undefined;
        ui.open();
      } catch { failed = true;
      } finally {
        mounted?.destroy();
        await candidate?.dispose();
        if (current === attempt) {
          current = undefined;
          if (failed && !destroyed && connected() && loadingDialog.open) {
            status.textContent = 'Search could not load. Retry, or close this window and browse the guide.';
            if (!destroyed && !current && connected() && loadingDialog.open) retry.hidden = false;
          } else if (!ui) hideLoading(attempt.opener);
        }
      }
    });
    attempts.add(attempt.promise);
    // The settled attempt cannot erase a newer rapid-reopen attempt.
    void attempt.promise.finally(() => attempts.delete(attempt.promise)).catch(() => {});
    retry.hidden = true;
    if (!live()) return attempt.promise;
    status.textContent = 'Loading search. You can browse the guide after closing this window.';
    if (!live()) return attempt.promise;
    try { loadingDialog.showModal(); if (live() && loadingDialog.open) closeButton.focus({ preventScroll: true }); }
    catch { if (current === attempt) current = undefined; attempt.abort.abort(); }
    return attempt.promise;
  }
  function onTrigger() { if (!ui) void open(true).catch(() => {}); }
  function onCancel(event) { event.preventDefault(); close(); }
  function onNativeClose() { if (!loadingDialog.open && !ui) close(); }
  function onRetry() { hideLoading(loadingOpener); void open().catch(() => {}); }
  function destroy() {
    if (disposal) return disposal;
    let resolve, reject;
    disposal = new Promise((yes, no) => { resolve = yes; reject = no; });
    destroyed = true;
    trigger.removeEventListener('click', onTrigger);
    closeButton.removeEventListener('click', close);
    retry.removeEventListener('click', onRetry);
    loadingDialog.removeEventListener('cancel', onCancel);
    loadingDialog.removeEventListener('close', onNativeClose);
    const attempt = current, mounted = ui, previous = owned;
    current = undefined; ui = undefined; owned = undefined;
    attempt?.abort.abort();
    mounted?.destroy();
    hideLoading(attempt?.opener);
    trigger.hidden = original.hidden;
    retry.hidden = original.retryHidden;
    status.replaceChildren(...original.status);
    Promise.all([...attempts, previous?.dispose()]).then(resolve, reject);
    return disposal;
  }
  trigger.addEventListener('click', onTrigger);
  closeButton.addEventListener('click', close);
  retry.addEventListener('click', onRetry);
  loadingDialog.addEventListener('cancel', onCancel);
  loadingDialog.addEventListener('close', onNativeClose);
  trigger.hidden = false;
  return Object.freeze({ open, close, destroy });
}

How this example works

Open search from a button, find a matching page and jump to the heading that contains the match. Copy a complete browser or Astro project, replace its explicit page content and adjust the CSS.

Use the modal for search behind a button. Choose inline search when the field and results should stay in the page.

For a compact field in an ordinary header, choose the dropdown header starter, with a real inline full-results destination.

Each project uses the native documentation modal and one indexed record per page. Optional source evidence and section maps provide anchored previews while native page totals, order and paging stay authoritative. These projects load a complete local index on first open; they do not crawl HTML or load index shards.

The wrappers own newly created search engines and destroy the borrowed UI before disposing them. To use an engine owned elsewhere, mount the modal directly and keep disposal with that existing owner. Query preservation, reset policy, retry and close/destroy behavior are described in both guides.
