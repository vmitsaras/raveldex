# Browser rich-results starter

Copy this complete resource directory, replace the explicit public records and adjust a few CSS properties. Search `walking resource`: seven genuine native matches span three pages. Choose List, Cards or Grid, adjust density and opt into local illustrations with **Show images**. Query, selections, native order, page and exact total stay the same. Every result opens a real generated resource page; the complete browse list also works without JavaScript.

## Copy, install and run

Use Node 22 or later and npm. Extract the complete starter into an empty directory with `tar -xzf cards-browser.tar.gz --strip-components=1`, then enter that directory. From a source checkout, you can instead copy the complete `examples/cards-browser/` folder to a new project.

Install Raveldex and the starter's pinned build tooling, then build and preview:

```sh
npm install @vmitsaras/raveldex@1.0.0
npm run build
npm run preview -- --port 4179
```

Keep the generated `package-lock.json` and use `npm ci` for subsequent installs. To test a local Raveldex build, substitute its core tarball path for the package name in the install command.

Open `http://127.0.0.1:4179/`. Stop the preview with Ctrl+C.

Serve over HTTP(S). This project imports the separate directory controller, optional card view, base directory stylesheet and card stylesheet explicitly. Filters/facets are configured in `configuration.mjs`; it does not select snippets, a worker, storage, crawling, commerce actions or full-set sorting.

## Deploy under a subdirectory

Use the same slash-terminated base for build and preview:

```sh
RAVELDEX_CARDS_BASE=/help/ npm run build
RAVELDEX_CARDS_BASE=/help/ npm run preview -- --port 4179
```

Open `http://127.0.0.1:4179/help/`. Deploy all rebuilt `dist/` files there, including content, images and resource routes. Paths resolve from the bundle/content base; `/help/` does not require runtime code changes.

## Replace data and display metadata

Edit `content.json`, then rebuild. `id`, `title`, `body`, `format`, `topics` and unique `/resources/slug/` paths are the searchable resource data. `load.mjs` indexes title/body and native format/topics only. It explicitly maps optional `excerpt`, `category`, `breadcrumb`, `date`, `fields` and `image` into display documents. None of these extra display values changes the native ranking or filter schema. Dates are authored localized text. Breadcrumbs are text segments, without invented navigation. Each named field is an explicit `{ "name": "Format", "value": "Field guide" }` pair.

Try changing the first title to `Plan a riverside walking trip`, adding `Riverside paths are part of this walking resource.` to its body and replacing its excerpt. Rebuild, search `riverside`, switch Grid/Compact and follow the actual changed page. Missing optional fields simply have no presentation. Text is inserted safely; HTML strings stay literal text.

The example admits up to 1,000 records and 4,000,000 aggregate serialized text units, refuses more than 4MiB fetched UTF-8 JSON, and indexes in batches of 100. ID/title/body/path bounds are 256/1,024/50,000/128 UTF-16 units. Optional excerpt/category/date bounds are 2,048/256/256; breadcrumbs contain up to eight 256-unit strings and fields up to four name/value pairs (128/512 units). These are example admission bounds, not memory or latency claims. Match records, `groups`, `labels` and the native schema in `configuration.mjs` when changing filter values.

## Images are an explicit choice

`settings.presentation` starts with `layout: 'list'`, `density: 'comfortable'`, `images: false`. No result image elements or requests are created until **Show images** is checked. List, Cards and Grid all support the same optional images. Enabling images affects only the current native page. The view validates HTTP(S) image URLs without credentials, explicit alternative text and dimensions; local sample paths resolve relative to the content base. Requests use native lazy loading, async decoding and no-referrer policy. Turning images off removes the image presentation; already started browser requests are not a cancellation guarantee.

`images/map.svg` has informative authored alternative text. `images/weather.svg` deliberately uses `alt: ""` because its illustration repeats the adjacent weather title. Both reserve 640×360 dimensions. The final resource deliberately points at missing `images/unavailable.svg` to demonstrate readable broken-image recovery: enabling images on that page keeps the resource title, link and metadata usable. No automatic image retry occurs.

When adding assets, change the explicit allowlist in `content.mjs`, the copy list in `build.mjs` and `package.json` together. Do not point to private or unapproved remote image hosts. The example performs no extraction or automatic image discovery.

## Change layout, density and CSS

The native appearance controls call only `view.setPresentation(...)`. They do not query the engine or write URL state. Change `settings.presentation` for initial presentation; these preferences are in memory and reset on a fresh page load. The directory URL still describes query, filters and page.

`main.mjs` loads `directory.css`, then `directory-cards.css`, then `theme.css`. Edit the existing component rules:

```css
.raveldex-directory {
  --raveldex-directory-accent: #145b45;
  --raveldex-directory-button-color: #fff;
  --raveldex-directory-radius: .75rem;
  --raveldex-directory-card-min-width: 17rem;
  --raveldex-directory-card-gap: 1.25rem;
  --raveldex-directory-card-radius: 1rem;
}
```

Stop preview, rebuild and restart with the same base. Reload: the accent is green, corners are rounder and card spacing is wider. Update the matching dark-theme rule too. Switch Grid/Compact, follow Tab order and browse all pages: visible sequence and DOM reading order remain native. Set background/color/muted/border/focus colors together to preserve contrast. Private `--_` properties and `data-*` hooks are implementation details.

## Query, navigation and ownership

The application owns one native engine, a borrowed-engine directory controller, one optional URL binding and one borrowed card view. The same native checkboxes, counts, chips, Clear all, mobile disclosure, error/revision recovery and complete pagination are used as the plain resource directory. OR combines choices in one group; AND combines groups and text. Counts include every active filter before native paging, including the group's own selections. Zero-count choices remain usable; unavailable counts are named explicitly.

`settings` explicitly enables URL synchronization with push for committed query/filter/page changes. Named parameters are `q`, `page`, `format` and repeated `topic`. Back/Forward replays coherent state without another entry; unrelated parameters/hash/history.state survive. Choose `history: 'replace'` for edits in one entry or `urlState: false` for in-memory search. Invalid links visibly recover. A refused address write keeps search usable; **Update search link** retries without querying again.

`controller.mjs` deduplicates loading, preserves fallback browse links on failure and exposes genuine Retry. It removes native appearance listeners and destroys view, URL binding and controller before disposing only its owned engine. Await `destroy()` when removing the application. A late owner is released even if a custom loader ignores abort. `main.mjs` waits for teardown on pagehide and recreates after persisted pageshow. A custom loader transfers ownership; do not return a borrowed shared engine.

## Check your content and theme

Use native Tab/Enter/Space for links and controls. Filter resources is a native disclosure, initially closed at all widths. Close filters/Escape restores summary focus; removing a chip recovers adjacent focus. Layout/density changes preserve focused result links. No interactive ARIA grid is introduced.

Check all native pages, metadata omissions, long and RTL text, images off/on/broken, zero results, loading/Retry, Back/Forward, teardown, light/dark/forced colors and reduced motion. Automated browser/axe and emulated viewport checks are distinct from human screen-reader speech, physical IME/touch/mobile keyboards, real 200%/400% browser zoom, Safari/device support and hosted deployment. Verify those in your target application.

import { groups } from './configuration.mjs';
const imagePaths = new Set(['images/map.svg', 'images/weather.svg', 'images/unavailable.svg']);
export function validateContent(entries) {
  if (!Array.isArray(entries) || entries.length > 1000) throw new Error('Expected up to 1000 explicit public resources');
  const ids = new Set(), paths = new Set(); let units = 0;
  const string = (value, limit) => typeof value === 'string' && value.length <= limit && value.isWellFormed();
  const readable = (value,limit,empty=false) => string(value,limit) && (empty&&value==='' || !/^[\s\p{C}]*$/u.test(value));
  const keys = (value, allowed) => value && typeof value === 'object' && !Array.isArray(value) && Object.keys(value).every(key=>allowed.includes(key));
  for (const entry of entries) {
    if (!keys(entry,['id','title','body','format','topics','path','excerpt','category','breadcrumb','date','fields','image'])
      || !string(entry.id,256) || !entry.id || ids.has(entry.id) || !readable(entry.title,1024)
      || !string(entry.body,50000) || !string(entry.path,128) || !/^\/resources\/[a-z0-9-]+\/$/.test(entry.path) || paths.has(entry.path)
      || !groups[0].values.includes(entry.format) || !Array.isArray(entry.topics) || entry.topics.length > 8
      || new Set(entry.topics).size !== entry.topics.length || !entry.topics.every(value => groups[1].values.includes(value))
      || ['excerpt','category','date'].some(key=>entry[key]!==undefined&&!readable(entry[key],key==='excerpt'?2048:256,true))
      || entry.breadcrumb!==undefined&&(!Array.isArray(entry.breadcrumb)||entry.breadcrumb.length>8||!entry.breadcrumb.every(value=>readable(value,256)))
      || entry.fields!==undefined&&(!Array.isArray(entry.fields)||entry.fields.length>4||new Set(entry.fields.map(field=>field?.name)).size!==entry.fields.length||!entry.fields.every(field=>keys(field,['name','value'])&&readable(field.name,128)&&readable(field.value,512)))
      || entry.image!==undefined&&(!keys(entry.image,['src','alt','width','height'])||!imagePaths.has(entry.image.src)||!readable(entry.image.alt,1024,true)||entry.image.width!==640||entry.image.height!==360)) throw new Error('Invalid or duplicate resource record');
    ids.add(entry.id); paths.add(entry.path); units += JSON.stringify(entry).length;
    if (units > 4000000) throw new Error('Resource text exceeds the example limit');
  }
  return entries;
}

const mime = { '.html': 'text/html; charset=utf-8', '.json': 'application/json; charset=utf-8', '.js': 'text/javascript; charset=utf-8', '.css': 'text/css; charset=utf-8', '.svg': 'image/svg+xml' };
const server = createServer(async (request, response) => {
  try {
    const pathname = new URL(request.url, 'http://localhost').pathname;
    if (!pathname.startsWith(base)) { response.writeHead(404).end(); return; }
    let file = resolve(root, decodeURIComponent(pathname.slice(base.length)));
    if (file !== root && !file.startsWith(root + '/')) { response.writeHead(403).end(); return; }
    if ((await stat(file)).isDirectory()) file = join(file, 'index.html');
    const bytes = await readFile(file);
    response.writeHead(200, { 'content-type': mime[extname(file)] ?? 'application/octet-stream', 'cache-control': 'no-store' }).end(bytes);
  } catch { response.writeHead(404).end(); }
});
server.listen(port, '127.0.0.1', () => console.log(`Open http://127.0.0.1:${port}${base} — Ctrl+C stops this preview.`));

import { createDirectory, connectDirectoryURL } from '@vmitsaras/raveldex/addons/ui/directory';

// This application owns only owners transferred by load(signal). The view itself
// borrows the controller, and the controller borrows that owner's engine.
export function createCardSearch({ root, status, retry, load, urlStatus, urlRetry, urlState = settings.urlState, presentationControls, layout, density, images }) {
  let owner, controller, view, binding, unobserve, pending, ended = false, epoch = 0, disposal;
  const presentation = () => ({ layout:layout?.value??settings.presentation.layout,density:density?.value??settings.presentation.density,images:images?.checked??settings.presentation.images });
  if(layout)layout.value=settings.presentation.layout;if(density)density.value=settings.presentation.density;if(images)images.checked=settings.presentation.images;
  if(presentationControls)presentationControls.disabled=true;
  const updatePresentation=()=>{ if(!ended&&view)view.setPresentation(presentation()); };
  for(const control of [layout,density,images])control?.addEventListener('change',updatePresentation);
  const say = text => { status.textContent = text; };
  function showURL(connected) {
    if (ended || !connected) return;
    const snapshot=connected.getSnapshot();
    const text=snapshot.status==='error' ? 'Search works, but the address could not be updated. Try updating the search link.'
      : snapshot.issues.length ? 'Some search link values were reset. The current filters are shown.' : '';
    if (urlStatus) { urlStatus.hidden=!text; if (urlStatus.textContent!==text) urlStatus.textContent=text; }
    if (!ended && urlRetry) urlRetry.hidden=snapshot.status!=='error';
  }
  function start() {
    if (ended || owner) return Promise.resolve();
    if (pending) return pending.promise;
    const ticket = ++epoch, abort = new AbortController();
    const job = { cancel: () => abort.abort(), promise: undefined };
    pending = job;
    job.promise = Promise.resolve().then(async () => {
      let candidate, directory, mounted, connected, observe, failed = false;
      const cancelViews = () => { observe?.(); observe=undefined; mounted?.destroy(); connected?.destroy(); directory?.destroy(); };
      job.cancel = () => { abort.abort(); cancelViews(); };
      try {
        if (ended || ticket !== epoch) return;
        retry.hidden = true; say('Loading directory. You can browse the resources below.');
        if (ended || ticket !== epoch) return;
        candidate = await load(abort.signal);
        if (ended || ticket !== epoch) return;
        directory = createDirectory({ engine:candidate.engine,groups,pageSize:settings.pageSize,mode:settings.mode });
        mounted = mountRaveldexDirectoryCards({ root,controller:directory,documents:candidate.documents,groups:labels,debounceMs:settings.debounceMs,presentation:presentation(),
          messages:{label:'Search walking resources',placeholder:'Try maps or weather'} });
        if (ended || ticket !== epoch) return;
        if (urlState) connected = connectDirectoryURL({ controller:directory,host:root.ownerDocument.defaultView,parameters:settings.parameters,history:settings.history });
        if (ended || ticket !== epoch) return;
        if (connected) await connected.read(); else await directory.refresh();
        if (ended || ticket !== epoch) return;
        if (connected) {
          const host=root.ownerDocument.defaultView;
          const update=()=>{ if (!ended && ticket===epoch) showURL(connected??binding); };
          const off=directory.subscribe(update);
          observe=()=>{ off();host.removeEventListener('popstate',update); };
          host.addEventListener('popstate',update);
        }
        // Publish every resource before authored status callbacks can destroy.
        owner=candidate;controller=directory;view=mounted;binding=connected;unobserve=observe;
        candidate=directory=mounted=connected=observe=undefined;
        if(presentationControls)presentationControls.disabled=false;
        showURL(binding);
        if (!ended && ticket===epoch) say('Directory is ready.');
      } catch { failed=true; }
      finally {
        cancelViews();
        await candidate?.dispose();
        if (pending === job) pending=undefined;
        if (failed && !ended && ticket===epoch) {
          retry.textContent='Retry loading directory';
          say('Directory could not load. Retry, or browse the resources below.');
          if (!ended && ticket===epoch) retry.hidden=false;
        }
      }
    });
    return job.promise;
  }
  const click = () => { void start(); };
  const retryURL=()=>{ if (!ended && binding) { binding.write();showURL(binding); } };
  retry.addEventListener('click',click);
  urlRetry?.addEventListener('click',retryURL);
  if (urlStatus) urlStatus.hidden=true;
  if (urlRetry) urlRetry.hidden=true;
  retry.hidden=false;retry.textContent='Enable directory';
  say('Browse the resources below, or enable the directory.');
  function destroy() {
    if (disposal) return disposal;
    let finish, fail; disposal=new Promise((resolve,reject)=>{finish=resolve;fail=reject;});
    ended=true;epoch++;
    const previous=owner, previousView=view, previousBinding=binding, previousController=controller, stopObserve=unobserve, work=pending;
    owner=controller=view=binding=unobserve=undefined;
    for(const control of [layout,density,images])control?.removeEventListener('change',updatePresentation);
    if(presentationControls)presentationControls.disabled=true;
    retry.removeEventListener('click',click);urlRetry?.removeEventListener('click',retryURL);stopObserve?.();work?.cancel();previousView?.destroy();previousBinding?.destroy();previousController?.destroy();
    if (urlStatus) urlStatus.hidden=true;
    if (urlRetry) urlRetry.hidden=true;
    retry.hidden=true;say('Directory is closed. Browse the resources below.');
    Promise.all([work?.promise,Promise.resolve().then(()=>previous?.dispose())]).then(finish,fail);
    return disposal;
  }
  return Object.freeze({start,destroy});
}

import { createRaveldex } from '@vmitsaras/raveldex';
import { configuration } from './configuration.mjs';
import { validateContent } from './content.mjs';
export async function loadResources(contentUrl, signal) {
  const response = await fetch(contentUrl, { signal, cache: 'no-cache' });
  if (!response.ok) throw new Error('Resource data is unavailable');
  const bytes = new Uint8Array(await response.arrayBuffer());
  if (bytes.length > 4 * 1024 * 1024) throw new Error('Resource data exceeds the example limit');
  const entries = validateContent(JSON.parse(new TextDecoder('utf-8', { fatal: true }).decode(bytes)));
  signal.throwIfAborted();
  const engine = createRaveldex(configuration());
  try {
    for (let offset=0; offset<entries.length; offset+=100) await engine.addMany(entries.slice(offset,offset+100).map(entry => ({ id:entry.id,
      text:{title:entry.title,body:entry.body},metadata:{format:entry.format,topics:entry.topics} })), { signal });
    signal.throwIfAborted();
    const base = new URL('./', contentUrl);
    return { engine, documents: entries.map(entry => ({ id:entry.id,title:entry.title,url:new URL(entry.path.slice(1),base).href,
      ...Object.fromEntries(['excerpt','category','breadcrumb','date','fields'].filter(key=>entry[key]!==undefined).map(key=>[key,entry[key]])),
      ...(entry.image?{image:{...entry.image,src:new URL(entry.image.src,base).href}}:{}) })), dispose:()=>engine.dispose() };
  } catch(error) { await engine.dispose(); throw error; }
}

How this example works

Present the same native directory results as a list, cards or a responsive grid. Add explicit excerpts, category/breadcrumb/date text, named fields and optional images. Copy the complete browser project, replace its public data and adjust a few CSS properties.

Map only the display data you need

The loader explicitly maps title/link plus optional excerpt, category, breadcrumb segments, authored localized date, named text fields and image information. The native index still uses title/body and the configured format/topics. Missing display metadata leaves readable title links. Strings stay literal text; no HTML template callback is accepted.

Each image declares a safe URL, explicit alternative and dimensions. Informative images describe their content; a repeated decorative illustration deliberately uses an empty alternative. The two local examples reserve 640×360 space. Images use native lazy loading and no-referrer policy. Failed images keep the text/link usable and do not retry automatically. Disabling images removes presentation; it does not promise cancellation of an already started browser request.
