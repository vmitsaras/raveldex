# Compact header search starter

Copy this complete plain-browser project to add a header dropdown with actual guide links and a full-results page. Search `walking guide`: the header shows three of seven matching pages. **See all results** opens the inline search at `search/`, where repeated Load more appends every match while retaining earlier results. The sample guide pages and browse links also work without JavaScript.

The starter creates one native engine per page. Header, inline results and an optional explicitly opened modal borrow that owner and use the same content and `mode: 'prefix'`. There is no crawler, suggestion service, provider registration, worker, storage, search history or second engine behind the modal.

## Copy, install and run

Use Node 22 or later and npm. Extract the complete starter into an empty directory with `tar -xzf dropdown-browser.tar.gz --strip-components=1`, then enter that directory. From a source checkout, you can instead copy the complete `examples/dropdown-browser/` folder to a new project.

Install Raveldex and the starter's pinned build tooling, then build and preview:

```sh
npm install @vmitsaras/raveldex@1.0.0
npm run build
npm run preview -- --port 4178
```

Keep the generated `package-lock.json` and use `npm ci` for subsequent installs. To test a local Raveldex build, substitute its core tarball path for the package name in the install command.

Open `http://127.0.0.1:4178/`. Stop the preview with Ctrl+C.

The quick header popup needs native manual Popover support; optional expanded search also uses native `dialog`. The normal full-results page can search without Popover support. Serve the built output over HTTP or HTTPS. Without native popovers, the header reveals an ordinary GET search form and explains the limitation. The header does not load an unused engine. Its real full-results page still mounts the inline interface, reads the original query and searches the same records. While a supported browser loads, the authored form stays hidden so mounting cannot discard a typed draft. Without JavaScript, the page offers browse links rather than a form that could not search. The public dropdown preset still refuses unsupported hosts; the starter does not install a positioning polyfill.

## Use a deployment base

Use the same base for build and preview:

```sh
RAVELDEX_DROPDOWN_BASE=/help/ npm run build
RAVELDEX_DROPDOWN_BASE=/help/ npm run preview -- --port 4178
```

Open `http://127.0.0.1:4178/help/`. The base must begin and end with `/`, using ordinary letters, digits, `_` or `-` in each segment. Deploy `dist/` under that base. Generated script/CSS/data, guide links and the real `/help/search/` route all follow it. Data and destination URLs resolve relative to the installed bundle, without assuming the site root. Rebuild after changing the base.

## Replace the records

Edit `content.json`, then rebuild. For example, change the first title to `Plan a riverside walking trip` and add `Riverside paths are part of this walking guide.` to its body. Reload, search `riverside`, and follow the actual new title to its generated guide page.

Every record has exactly `id`, `title`, `body`, `category` and `path` string fields. IDs and `/guides/slug/` paths are unique. Titles must contain non-whitespace text, use well-formed UTF-16 and fit within 1,024 UTF-16 units; valid surrounding whitespace is preserved. `content.mjs` validates at most 1,000 pages, ID/title/body/category/path limits of 256/1,024/50,000/120/128 UTF-16 units and 4,000,000 aggregate units; the loader admits at most 4MiB of UTF-8 JSON and indexes in batches of 100. These are finite example bounds, not speed or memory guarantees. All output is public and text is escaped; author real public content rather than HTML templates or secret records.

`load.mjs` maps title/body into native search text, with title boost two. Display records are `{id, title, url}` and category is only a visible guide label, not a facet. Header, full results and optional modal receive those same documents. To use existing pages, replace the explicit build/content mapping with the real public paths while retaining stable IDs and matching indexed/display content. This example does not extract HTML, snippets or section anchors.

## Full-results query meaning

`configuration.mjs` selects `mode: 'prefix'` once for all three presenters. Earlier words match exactly; only the final word can complete an indexed word. The native engine still owns membership, relevance order and exact totals. Header `maxResults: 3` is a finite projection, not pagination. The inline route appends batches of three until all matches are displayed. Its legacy `maxRenderedResults` setting remains accepted but does not impose a window or change continuation.

The dropdown configures the real `search/?from=header#results` destination. It replaces only `q`, preserving the static parameter/hash and the unchanged current field value. Spaces, punctuation, Unicode and literal percent signs are encoded with URLSearchParams, never trimmed or completed for the link. `readInitialQuery(location.search)` reads the full page's single `q` once. Duplicate `q`, malformed percent/UTF-8 encoding, malformed UTF-16, line breaks or more than 2,048 decoded UTF-16 units are refused with `The query link could not be read. Enter a new search below.` The inline field remains usable. Other parameters are ignored; no history or Back/Forward URL synchronization is installed. Editing the inline field does not rewrite the URL.

Use the same analyzer, content and mode when adapting the destination. Do not send a prefix query to an exact-word destination and describe the results as equivalent.

## Change a few CSS values

`main.mjs` explicitly imports the installed dropdown, inline and modal styles, then `theme.css`. Change the existing `.raveldex-dropdown` rule, rebuild and reload:

```css
.raveldex-dropdown {
  --raveldex-dropdown-accent: #145b45;
  --raveldex-dropdown-radius: .75rem;
  --raveldex-dropdown-gap: .75rem;
}
```

The accent, corners and space between controls change while `walking guide` still has seven matches. Tab through the input and buttons, search again, open full results and follow a native guide link. The inline route has a separate `.raveldex-inline` rule; modal layout uses `.raveldex-modal` while its result theme uses the inner `.raveldex-inline`. Edit complete background/text/muted/border/focus/active palettes together for dark themes. The included dark, forced-colors and reduced-motion rules demonstrate those states without hiding focus.

The header's native top-layer popup can escape an overflow/transform ancestor. Keep its input visible and leave the Search/Clear/full-results controls usable. The same compact layout remains at narrow widths. If neither side fits a usable result row, the runtime collapses the popup, reports exact totals with zero visible results and leaves **See all results** available. It does not automatically open another UI or engine. Scroll the page to reach long controls/labels; changing font size and resizing are separate from actual browser zoom or a physical mobile keyboard.

## Optional explicit modal handoff

The default `modalHandoff: false` in `configuration.mjs` keeps **Open expanded search** hidden. To demonstrate the optional handoff, change it to `true`, rebuild and reload. Enter ` walking guide `, wait for committed input, then activate **Open expanded search**. The header popup closes, a dialog opens, and its field retains those exact spaces and query meaning. Close search to return to the logical button. Narrowing the viewport never opens it automatically. A newer handoff, including a refused composing/invalid request, cancels an older reentrant focus/mount action before it can publish stale text.

`createHeaderSearch` owns the handoff button's click: it admits committed, valid text, closes the dropdown, mounts the modal lazily with the same owner/documents/mode, opens it and searches the exact raw field. Neither UI registers a global shortcut. Native modal opening/capability failures report `Expanded search could not open. Use the header or See all results.` and preserve the owner and original recovery route. A later successful handoff clears its own failure feedback; an unrelated refused full-results URL notice remains. The button listener prevents the modal preset's own trigger listener from bypassing refused composition/invalid-query handoffs. Native result and full-results anchors retain their ordinary activation.

All three presenter modules and styles are explicitly bundled for this complete demonstration. Turning the flag off prevents modal mounting; it is not a zero-byte build switch. A header-only application can remove the modal import/branch/button/styles together and measure its own build. The optional library entries themselves do not change core imports or initialize automatically.

## Loading, retry and cleanup

The loader is explicit on page initialization, including guide pages. While it loads, authored browse links remain usable. Block `content.json` to observe failure; unblock it and select **Load search again** to retry. There is one in-flight initialization per controller. `load(signal)` must transfer a **newly owned** `{engine, documents, dispose}`; never return an engine belonging to another component, because this wrapper disposes it. To borrow an existing application engine, mount the installed dropdown/inline/modal APIs directly and retain disposal with that application's owner.

`createHeaderSearch` takes `root`, `status`, `retry`, `load` and `fullResultsURL`, plus optional `fullRoot`, `initialQuery`, `queryRefused`, `modalRoot`, `modalTrigger` and `modalHandoff`. It returns `{start, openModal, destroy}`. `start()` deduplicates initialization, and `openModal()` only acts explicitly after a ready owner exists and the optional handoff is enabled. `destroy()` returns one stable Promise, invalidates callbacks, aborts loading, removes application listeners, destroys every borrowed presenter and waits for late owners/disposal. Call and await it before removing/replacing the integration. The public UI presets separately suppress stale search replies.

`main.mjs` destroys on `pagehide` and waits for that disposal before recreating on a persisted `pageshow`; overlapping navigation epochs cannot recreate an abandoned controller. It exposes no global debug API. There is no storage, telemetry or URL-state subscription.

Automated browser checks are supporting evidence. Human screen-reader speech, physical IME/touch/on-screen keyboards, actual 200%/400% zoom, Safari and other engine/device combinations need separate application observations. The recorded Playwright WebKit environment uses native Option+Tab control traversal and does not establish modified new-tab support; do not override native editing, links or OS preferences to simulate those claims.

// Header, full results and optional modal deliberately select the same query mode.
export const configuration = Object.freeze({
  mode: 'prefix',
  maxResults: 3,
  pageSize: 3,
  modalHandoff: false,
});

export function validQuery(value) {
  if (typeof value !== 'string' || value.length > 2048 || /[\r\n]/.test(value)) return false;
  for (let i = 0; i < value.length; i++) {
    const unit = value.charCodeAt(i);
    if (unit >= 0xd800 && unit <= 0xdbff) {
      const next = value.charCodeAt(++i);
      if (!(next >= 0xdc00 && next <= 0xdfff)) return false;
    } else if (unit >= 0xdc00 && unit <= 0xdfff) return false;
  }
  return true;
}

// Read q once. Do not trim/normalize it, rewrite history, or own other parameters.
export function readInitialQuery(search) {
  if (typeof search !== 'string') return { query: undefined, refused: true };
  let query, count = 0;
  for (const field of search.replace(/^\?/, '').split('&')) {
    const split = field.indexOf('='), key = split < 0 ? field : field.slice(0, split);
    let name;
    try { name = decodeURIComponent(key.replaceAll('+', ' ')); } catch { continue; }
    if (name !== 'q') continue;
    if (++count > 1) return { query: undefined, refused: true };
    const encoded = split < 0 ? '' : field.slice(split + 1);
    if (encoded.length > 24576) return { query: undefined, refused: true };
    try { query = decodeURIComponent(encoded.replaceAll('+', ' ')); }
    catch { return { query: undefined, refused: true }; }
    if (!validQuery(query)) return { query: undefined, refused: true };
  }
  return { query, refused: false };
}

content.mjs

// One explicit record per public page. This is an allowlist, not an HTML crawler.
export function prepareGuides(entries) {
  if (!Array.isArray(entries) || entries.length > 1000) throw new Error('Expected up to 1000 explicit guide records');
  const ids = new Set(), paths = new Set();
  let units = 0;
  return entries.map(entry => {
    if (!entry || typeof entry !== 'object' || Array.isArray(entry)
      || Object.keys(entry).sort().join(',') !== 'body,category,id,path,title') throw new Error('Invalid guide record');
    for (const [name, maximum] of [['id', 256], ['title', 1024], ['body', 50000], ['category', 120], ['path', 128]]) {
      const value = entry[name];
      if (typeof value !== 'string' || !value.length || value.length > maximum || !value.isWellFormed() || name === 'title' && !value.trim()) throw new Error('Invalid guide ' + name);
      units += value.length;
    }
    if (units > 4000000 || ids.has(entry.id) || paths.has(entry.path) || !/^\/guides\/[a-z0-9-]+\/$/.test(entry.path))
      throw new Error('Duplicate or invalid guide identity/path');
    ids.add(entry.id); paths.add(entry.path);
    return { id: entry.id, title: entry.title, body: entry.body, category: entry.category, path: entry.path };
  });
}

import { createServer } from 'node:http';
import { readFile, stat } from 'node:fs/promises';
import { dirname, extname, resolve, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const root = resolve(dirname(fileURLToPath(import.meta.url)), 'dist');
const base = process.env.RAVELDEX_DROPDOWN_BASE ?? '/';
if (!/^\/(?:[A-Za-z0-9_-]+\/)*$/.test(base)) throw new Error('Invalid deployment base');
const args = process.argv.slice(2), port = Number(args.length === 2 && args[0] === '--port' ? args[1] : args.length === 0 ? 4178 : NaN);
if (!Number.isInteger(port) || port < 1 || port > 65535) throw new Error('Use --port 4178');
const mime = { '.html': 'text/html; charset=utf-8', '.json': 'application/json; charset=utf-8', '.js': 'text/javascript; charset=utf-8', '.css': 'text/css; charset=utf-8' };
const server = createServer(async (request, response) => {
  try {
    const pathname = new URL(request.url, 'http://localhost').pathname;
    if (!pathname.startsWith(base)) { response.writeHead(404).end(); return; }
    let file = resolve(root, decodeURIComponent(pathname.slice(base.length)));
    if (file !== root && !file.startsWith(root + '/')) { response.writeHead(403).end(); return; }
    if ((await stat(file)).isDirectory()) file = join(file, 'index.html');
    const bytes = await readFile(file);
    response.writeHead(200, { 'content-type': mime[extname(file)] ?? 'application/octet-stream', 'cache-control': 'no-store' }).end(bytes);
  } catch { response.writeHead(404).end(); }
});
server.listen(port, '127.0.0.1', () => console.log(`Open http://127.0.0.1:${port}${base} — Ctrl+C stops this preview.`));

import '@vmitsaras/raveldex/addons/ui/dropdown.css';
import '@vmitsaras/raveldex/addons/ui/inline.css';
// Included explicitly for the documented opt-in modal demonstration.
import '@vmitsaras/raveldex/addons/ui/modal.css';
import './theme.css';
import { configuration, readInitialQuery } from './configuration.mjs';
import { createHeaderSearch } from './controller.mjs';
import { loadGuides } from './load.mjs';

const base = new URL('../', import.meta.url);
const root = document.querySelector('[data-search-root]');
const fullRoot = document.querySelector('[data-full-results-root]');
let search, epoch = 0, stopped = Promise.resolve();
function initialize() {
  const initial = fullRoot ? readInitialQuery(location.search) : { query: undefined, refused: false };
  search = createHeaderSearch({ root, fullRoot,
    status: document.querySelector('[data-search-status]'), retry: document.querySelector('[data-search-retry]'),
    modalRoot: document.querySelector('[data-search-modal-root]'), modalTrigger: document.querySelector('[data-search-modal-trigger]'),
    modalHandoff: configuration.modalHandoff,
    fullResultsURL: new URL('search/?from=header#results', base).href,
    initialQuery: initial.query, queryRefused: initial.refused,
    load: signal => loadGuides(new URL('content.json', base), signal) });
  void search.start();
}
initialize();
window.addEventListener('pagehide', () => {
  epoch++;
  const previous = search; search = undefined;
  stopped = Promise.all([stopped, previous?.destroy()]);
});
window.addEventListener('pageshow', event => {
  if (!event.persisted) return;
  const ticket = ++epoch;
  void stopped.then(() => { if (ticket === epoch) initialize(); });
});
controller.mjs

import { mountRaveldexDropdown } from '@vmitsaras/raveldex/addons/ui/dropdown';
import { mountRaveldexInline } from '@vmitsaras/raveldex/addons/ui/inline';
import { mountRaveldexModal } from '@vmitsaras/raveldex/addons/ui/modal';
import { configuration, validQuery } from './configuration.mjs';

// load(signal) transfers a NEW owner {engine, documents, dispose}. Presenters
// borrow it; this controller destroys every presenter before disposing it once.
export function createHeaderSearch({ root, status, retry, load, fullResultsURL,
  fullRoot, modalRoot, modalTrigger, initialQuery, queryRefused = false,
  modalHandoff = false }) {
  if (modalHandoff && (!modalRoot || !modalTrigger)) throw new Error('Expanded search needs its root and button');
  const doc = root.ownerDocument;
  let owner, dropdown, inline, modal, pending, abort, disposal;
  let ended = false, generation = 0, handoff = 0, composing = false;
  const jobs = new Set();
  const connected = () => [root, status, retry, ...(fullRoot ? [fullRoot] : []),
    ...(modalHandoff ? [modalRoot, modalTrigger] : [])].every(node => node.isConnected && node.ownerDocument === doc);
  const current = ticket => !ended && generation === ticket && connected();
  const say = text => { status.textContent = text; };
  const initialValid = initialQuery === undefined || validQuery(initialQuery);
  const refused = queryRefused || !initialValid;
  const modalError = 'Expanded search could not open. Use the header or See all results.';
  const handoffError = 'Finish entering a valid single-line query before opening expanded search.';

  function start() {
    if (ended || !connected()) return Promise.resolve();
    if (pending) return pending;
    if (owner) return Promise.resolve();
    const ticket = ++generation, signal = new AbortController();
    abort = signal;
    // Publish before status replacement, loader or authored disconnection callbacks.
    const work = Promise.resolve().then(async () => {
      let candidate, mountedDropdown, mountedInline, failed = false;
      try {
        if (!current(ticket)) return;
        retry.hidden = true;
        if (modalTrigger) modalTrigger.hidden = true;
        const probe = doc.createElement('div');
        const quickSearch = typeof probe.showPopover === 'function' && typeof probe.hidePopover === 'function';
        if (!quickSearch) { const form = root.querySelector('.header-search__fallback'); if (form) form.hidden = false; }
        if (!quickSearch && !fullRoot) {
          say('Quick search is unavailable in this browser. Use the search form or browse the guides.');
          return;
        }
        say('Loading search. You can browse the guides while it loads.');
        if (!current(ticket)) return;
        candidate = await load(signal.signal);
        if (!current(ticket)) return;
        if (quickSearch) mountedDropdown = mountRaveldexDropdown({ root, engine: candidate.engine, documents: candidate.documents,
          mode: configuration.mode, maxResults: configuration.maxResults, shortcut: false,
          fullResults: { url: fullResultsURL, queryParameter: 'q' },
          messages: { label: 'Search walking guides', placeholder: 'Try weather or walking guide' } });
        if (!current(ticket)) return;
        if (fullRoot) {
          mountedInline = mountRaveldexInline({ root: fullRoot, engine: candidate.engine, documents: candidate.documents,
            mode: configuration.mode, pageSize: configuration.pageSize,
            messages: { label: 'Search all walking guides', placeholder: 'Try weather or walking guide',
              idle: 'Enter a word to search all walking guides.' } });
          if (!current(ticket)) return;
        }
        // Publish owned views before an initial search or status/focus callback.
        owner = candidate; candidate = undefined;
        dropdown = mountedDropdown; mountedDropdown = undefined;
        inline = mountedInline; mountedInline = undefined;
        if (inline && !refused && initialQuery !== undefined) await inline.search(initialQuery);
        if (!current(ticket)) return;
        say(refused ? 'The query link could not be read. Enter a new search below.' : quickSearch ? 'Search is ready.'
          : 'Quick search is unavailable in this browser. Search all guides below or use the browse links.');
        if (current(ticket) && modalHandoff && quickSearch) modalTrigger.hidden = false;
      } catch {
        failed = true;
      } finally {
        try {
          mountedInline?.destroy(); mountedDropdown?.destroy();
          if (candidate) await candidate.dispose();
          if (failed && current(ticket)) {
            // This normally means loading/capture failed before ownership transfer.
            // If a host callback threw later, release that committed owner too.
            const previous = owner, previousDropdown = dropdown, previousInline = inline, previousModal = modal;
            owner = undefined; dropdown = undefined; inline = undefined; modal = undefined;
            previousModal?.destroy(); previousInline?.destroy(); previousDropdown?.destroy();
            if (previous) await previous.dispose();
            if (!current(ticket)) return;
            say('Search could not load. Browse the guides below or try loading again.');
            if (current(ticket)) retry.hidden = false;
          }
        } finally { if (pending === work) pending = undefined; }
      }
    });
    pending = work; jobs.add(work);
    void work.then(() => { jobs.delete(work); }, () => { jobs.delete(work); });
    return work;
  }

  function openModal() {
    // Even a refused newer handoff invalidates an older focus/mount callback.
    const request = ++handoff, ticket = generation;
    if (!modalHandoff || !owner || !dropdown || !current(ticket)) return Promise.resolve();
    const field = root.querySelector('[data-raveldex-dropdown-input]');
    const raw = field?.value ?? '';
    const active = () => current(ticket) && handoff === request && !composing &&
      field?.isConnected && root.contains(field) && field.value === raw;
    if (composing || !validQuery(raw)) {
      say(handoffError);
      return Promise.resolve();
    }
    let view;
    const failed = () => {
      if (!active()) return;
      // A native dialog refusal does not dispose the shared owner or replace
      // the header/full-results route with a pretend fallback.
      view?.close();
      if (active()) say(modalError);
    };
    try {
      dropdown.close();
      if (!active()) return Promise.resolve();
      if (!modal) {
        const mounted = mountRaveldexModal({ root: modalRoot, trigger: modalTrigger,
          engine: owner.engine, documents: owner.documents, mode: configuration.mode,
          pageSize: configuration.pageSize,
          shortcut: false, keyboardHints: false,
          messages: { label: 'Search walking guides in a dialog', placeholder: 'Try weather or walking guide' },
          modalMessages: { title: 'Search all walking guides' } });
        if (!active()) {
          // A nested handoff can have claimed the same-kind handle.
          if (modal !== mounted) mounted.destroy();
          return Promise.resolve();
        }
        modal = mounted;
      }
      view = modal;
      // This explicit button is the logical opener even where pointer activation
      // natively leaves focus on the field. Respect authored focus reentry.
      modalTrigger.focus({ preventScroll: true });
      if (!active() || modal !== view || doc.activeElement !== modalTrigger) return Promise.resolve();
      view.open();
      if (!active() || modal !== view || !modalRoot.querySelector('dialog[open]')) return Promise.resolve();
      // Clear only this handoff's prior error, retaining an unrelated refused
      // full-results URL notice. Status replacement can itself reenter/close.
      if (status.textContent === modalError || status.textContent === handoffError) say('Search is ready.');
      if (!active() || modal !== view || !modalRoot.querySelector('dialog[open]')) return Promise.resolve();
      const work = view.search(raw).catch(failed);
      jobs.add(work);
      void work.then(() => { jobs.delete(work); }, () => { jobs.delete(work); });
      return work;
    } catch {
      failed();
      return Promise.resolve();
    }
  }
  const onRetry = () => { void start(); };
  const onModal = event => {
    // This application button owns admission/query transfer. The modal preset
    // also registers a trigger listener; do not let it reopen a refused handoff.
    event.stopImmediatePropagation();
    void openModal();
  };
  const onCompositionStart = () => { composing = true; };
  const onCompositionEnd = () => { composing = false; };
  retry.addEventListener('click', onRetry);
  if (modalHandoff) modalTrigger.addEventListener('click', onModal);
  root.addEventListener('compositionstart', onCompositionStart, true);
  root.addEventListener('compositionend', onCompositionEnd, true);
  if (modalTrigger) modalTrigger.hidden = true;

  function destroy() {
    if (ended) return disposal;
    ended = true; generation++; handoff++;
    let resolve, reject;
    // Stable disposal exists before abort/DOM/focus callbacks can reenter.
    disposal = new Promise((done, fail) => { resolve = done; reject = fail; });
    const previous = owner, previousDropdown = dropdown, previousInline = inline, previousModal = modal;
    owner = undefined; dropdown = undefined; inline = undefined; modal = undefined;
    const work = [...jobs];
    abort?.abort();
    retry.removeEventListener('click', onRetry);
    if (modalHandoff) modalTrigger.removeEventListener('click', onModal);
    root.removeEventListener('compositionstart', onCompositionStart, true);
    root.removeEventListener('compositionend', onCompositionEnd, true);
    previousModal?.destroy(); previousInline?.destroy(); previousDropdown?.destroy();
    retry.hidden = true;
    if (modalTrigger) modalTrigger.hidden = true;
    say('Search is closed. Browse the guides below.');
    Promise.all([...work, Promise.resolve().then(() => previous?.dispose())]).then(resolve, reject);
    return disposal;
  }
  return Object.freeze({ start, openModal, destroy });
}

import { createRaveldex } from '@vmitsaras/raveldex';
import { prepareGuides } from './content.mjs';

export async function loadGuides(contentURL, signal) {
  const response = await fetch(contentURL, { signal, cache: 'no-cache' });
  if (!response.ok || !response.body) throw new Error('Guide data is unavailable');
  const reader = response.body.getReader(), chunks = [];
  let bytes = 0;
  try {
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      bytes += value.byteLength;
      if (bytes > 4194304) throw new Error('Guide data exceeds the 4MiB example limit');
      chunks.push(value);
    }
  } catch (error) { await reader.cancel().catch(() => {}); throw error; }
  finally { reader.releaseLock(); }
  signal.throwIfAborted();
  const joined = new Uint8Array(bytes);
  let at = 0;
  for (const chunk of chunks) { joined.set(chunk, at); at += chunk.length; }
  const entries = prepareGuides(JSON.parse(new TextDecoder('utf-8', { fatal: true }).decode(joined)));
  signal.throwIfAborted();
  const engine = createRaveldex({ schema: { text: { title: { boost: 2 }, body: {} } } });
  try {
    for (let offset = 0; offset < entries.length; offset += 100) {
      await engine.addMany(entries.slice(offset, offset + 100).map(entry => ({ id: entry.id,
        text: { title: entry.title, body: entry.body } })), { signal });
    }
    signal.throwIfAborted();
    const base = new URL('./', contentURL);
    return { engine, documents: entries.map(entry => ({ id: entry.id, title: entry.title,
      url: new URL(entry.path.slice(1), base).href })), dispose: () => engine.dispose() };
  } catch (error) { await engine.dispose(); throw error; }
}

It transfers the current header query into the existing native modal, sharing the page's owner, records and prefix mode. It adds no competing global shortcut or second engine. The default is false. The supplied build includes the modal code and explicit stylesheet so this switch can be tried without changing imports; its setup guide explains that cost and how the surfaces share ownership.

Keep the complete results route and browse links usable before loading, after a loading failure and without JavaScript. Rebuild and deploy the pages, content and assets together when changing the base or records.

Before using your own theme

Installed-consumer checks and the acceptance record describe the tested browser, lifecycle and emulated layout scope. Human screen-reader speech, physical IME/touch/on-screen keyboards, actual browser zoom and other browser/device combinations need separate checks in your application. See starter adoption and local checks. Playwright WebKit observations do not establish Safari support.
