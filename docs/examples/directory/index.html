# Browser resource-directory starter

Copy this complete project to search a public resource library with checkboxes, removable selected filters and complete result pages. Search `walking resource`: all seven pages match. Filter by resource type and topic, remove a chip or choose **Clear all**. Every result opens a real generated resource page. The browse list also works without JavaScript.

The application owns one native engine, one directory controller, its optional URL binding and one borrowed view. Filters use OR within a group and AND across groups/text. Counts include every active filter, including the group's own selections, before result paging. A count describes the current matches; it does not predict what adding another OR choice will do. Zero-count choices remain usable.

## Copy, install and run

Use Node 22 or later and npm. Extract the complete starter into an empty directory with `tar -xzf directory-browser.tar.gz --strip-components=1`, then enter that directory. From a source checkout, you can instead copy the complete `examples/directory-browser/` folder to a new project.

Install Raveldex and the starter's pinned build tooling, then build and preview:

```sh
npm install @vmitsaras/raveldex@1.0.0
npm run build
npm run preview -- --port 4179
```

Keep the generated `package-lock.json` and use `npm ci` for subsequent installs. To test a local Raveldex build, substitute its core tarball path for the package name in the install command.

Open `http://127.0.0.1:4179/`. Stop the preview with Ctrl+C.

Serve output over HTTP(S). The browser uses native forms, checkboxes and a details disclosure. No Popover, dialog, snippets, worker, storage or search-history feature is selected. Explicit filters and facets are installed in `configuration.mjs`; missing capabilities remain visible errors.

## Deploy under a subdirectory

Use the same slash-terminated base for build and preview:

```sh
RAVELDEX_DIRECTORY_BASE=/help/ npm run build
RAVELDEX_DIRECTORY_BASE=/help/ npm run preview -- --port 4179
```

Open `http://127.0.0.1:4179/help/`. Deploy the rebuilt `dist/` there, including assets, content and resource pages. The base allows ordinary letters, numbers, `_` and `-` path segments. URLs resolve from the bundle/content location, including `/help/resources/maps/`; no runtime path assumes the domain root.

## Replace content and labels

Edit `content.json`, then rebuild. Each entry has `id`, `title`, `body`, `format`, `topics` and `path`. IDs and `/resources/slug/` paths are unique. Change the first title to `Plan a riverside walking trip` and append `Riverside paths are part of this walking resource.` to its body. Rebuild, search `riverside` and follow the actual changed page.

`content.mjs` validates up to 1,000 explicit pages and 4,000,000 aggregate text units. ID/title/body/path bounds are 256/1,024/50,000/128 UTF-16 units. Topics are a distinct array of up to eight configured strings. The loader refuses more than 4MiB of fetched UTF-8 JSON and indexes in batches of 100. These are admission limits, not latency/memory guarantees. All generated data is public. The build escapes text and creates only the declared resource routes; it does not crawl HTML.

`configuration.mjs` declares native title/body text, title boost two, one scalar string `format` and multi-value string `topics`. Its `groups` list owns allowed filter values; `labels` supplies visible field/value labels. Change matching records, allowed values and labels together. `settings` selects prefix mode, a three-result native page, input debounce and URL policy. Earlier words match exactly; the final word may complete a native word. Native relevance order, ties and totals remain authoritative. No full-set sorting or card/image renderer is added.

## URL state and navigation

This starter explicitly selects `urlState: true` and `history: 'push'`. Named parameters are `q`, `page`, `format` and repeated `topic`. Each debounced text commit, explicit Search, checkbox change, chip removal, Clear all or page change can create a history entry when state changes. Back/Forward replays coherent text/filters/page without pushing another entry. Choose `history: 'replace'` to keep live edits in the current entry, or `urlState: false` to leave the URL untouched and browse only in memory. Connect the binding before the initial read/query, as `controller.mjs` does.

Unrelated raw parameters, pathname/hash and history.state survive. Invalid/stale owned values recover with the existing bounded URL codec. Query/filter changes reset page one; stale native revisions show **Refresh results**. A refused history write leaves search usable and shows an address-update message. **Update search link** retries the current state with replace, without another query. Corrected invalid link values have a visible notice.

Only one controller may claim a given parameter name on a host. Give separately configured application instances disjoint names; this starter mounts one per page. URL state is explicit session-history integration, with no localStorage, retained search-history store or telemetry.

`main.mjs` imports the package's explicit `directory.css`, then `theme.css`. In the existing `.raveldex-directory` rule, change these values:

Stop preview, rebuild and restart it with the same base, then reload. The accent is green, corners are rounder and filter/result spacing is wider. Search `walking resource` again: seven pages still match, three appear per page, and **Next page** reaches the other matches. Check Tab focus and follow a real result. For dark colors, change the matching media rule too. Supported properties also include background, color, muted, border, focus and padding; set related colors together to preserve contrast. Private `--_` variables and `data-*` hooks are implementation details.

## Keyboard, mobile filters and recovery

Search/checkboxes/buttons/links use native Tab, Enter and Space behavior. **Filter resources** opens a native disclosure at every width; it defaults closed. Close filters or Escape inside it returns focus to its summary. Resizing does not silently close focused filters. Removing a selected-filter chip focuses the next chip, previous chip or search input. Clear all retains its button. A selected zero or projected-out value remains checked and removable; omitted counts are labeled unavailable rather than invented as zero.

Typing waits for composition to finish. Loading, no results, native failure and revised collections have visible live status and recovery. No-results can recover by removing chips or clearing all. Initialization fetch/validation/mount failures retain the authored browse links and show **Retry loading directory**. The view does not silently install missing capabilities.

`controller.mjs` deduplicates start, aborts loading and releases a late owner even if its loader ignores abort. Destroy tears down view, URL binding and controller before disposing only the owned engine. Main waits for teardown on pagehide and recreates the application after persisted pageshow. Call/await `destroy()` when removing the application. Do not supply a borrowed engine from `load`: this wrapper owns and disposes the returned candidate.

Before adopting your theme, check keyboard, chip focus, mobile disclosure, all pages, Back/Forward, zero results, loading/retry, long/RTL labels, dark/forced colors and reduced motion. Scripted browser/axe/reflow checks do not establish human screen-reader speech, physical IME/touch/on-screen keyboard or actual 200%/400% browser zoom; check those in your target application. Playwright WebKit is not Safari qualification.

import { groups } from './configuration.mjs';
export function validateContent(entries) {
  if (!Array.isArray(entries) || entries.length > 1000) throw new Error('Expected up to 1000 explicit public resources');
  const ids = new Set(), paths = new Set(); let units = 0;
  const string = (value, limit) => typeof value === 'string' && value.length <= limit && value.isWellFormed();
  for (const entry of entries) {
    if (!entry || Object.keys(entry).sort().join(',') !== 'body,format,id,path,title,topics'
      || !string(entry.id,256) || !entry.id || ids.has(entry.id) || !string(entry.title,1024) || !entry.title.trim()
      || !string(entry.body,50000) || !string(entry.path,128) || !/^\/resources\/[a-z0-9-]+\/$/.test(entry.path) || paths.has(entry.path)
      || !groups[0].values.includes(entry.format) || !Array.isArray(entry.topics) || entry.topics.length > 8
      || new Set(entry.topics).size !== entry.topics.length || !entry.topics.every(value => groups[1].values.includes(value))) throw new Error('Invalid or duplicate resource record');
    ids.add(entry.id); paths.add(entry.path); units += entry.id.length + entry.title.length + entry.body.length + entry.path.length + entry.format.length + entry.topics.join('').length;
    if (units > 4000000) throw new Error('Resource text exceeds the example limit');
  }
  return entries;
}

import { createDirectory, connectDirectoryURL } from '@vmitsaras/raveldex/addons/ui/directory';
import { mountRaveldexDirectory } from '@vmitsaras/raveldex/addons/ui/directory/view';
import { groups, labels, settings } from './configuration.mjs';

// This application owns only owners transferred by load(signal). The view itself
// borrows the controller, and the controller borrows that owner's engine.
export function createDirectorySearch({ root, status, retry, load, urlStatus, urlRetry, urlState = settings.urlState }) {
  let owner, controller, view, binding, unobserve, pending, ended = false, epoch = 0, disposal;
  const say = text => { status.textContent = text; };
  function showURL(connected) {
    if (ended || !connected) return;
    const snapshot=connected.getSnapshot();
    const text=snapshot.status==='error' ? 'Search works, but the address could not be updated. Try updating the search link.'
      : snapshot.issues.length ? 'Some search link values were reset. The current filters are shown.' : '';
    if (urlStatus) { urlStatus.hidden=!text; if (urlStatus.textContent!==text) urlStatus.textContent=text; }
    if (!ended && urlRetry) urlRetry.hidden=snapshot.status!=='error';
  }
  function start() {
    if (ended || owner) return Promise.resolve();
    if (pending) return pending.promise;
    const ticket = ++epoch, abort = new AbortController();
    const job = { cancel: () => abort.abort(), promise: undefined };
    pending = job;
    job.promise = Promise.resolve().then(async () => {
      let candidate, directory, mounted, connected, observe, failed = false;
      const cancelViews = () => { observe?.(); observe=undefined; mounted?.destroy(); connected?.destroy(); directory?.destroy(); };
      job.cancel = () => { abort.abort(); cancelViews(); };
      try {
        if (ended || ticket !== epoch) return;
        retry.hidden = true; say('Loading directory. You can browse the resources below.');
        if (ended || ticket !== epoch) return;
        candidate = await load(abort.signal);
        if (ended || ticket !== epoch) return;
        directory = createDirectory({ engine:candidate.engine,groups,pageSize:settings.pageSize,mode:settings.mode });
        mounted = mountRaveldexDirectory({ root,controller:directory,documents:candidate.documents,groups:labels,debounceMs:settings.debounceMs,
          messages:{label:'Search walking resources',placeholder:'Try maps or weather'} });
        if (ended || ticket !== epoch) return;
        if (urlState) connected = connectDirectoryURL({ controller:directory,host:root.ownerDocument.defaultView,parameters:settings.parameters,history:settings.history });
        if (ended || ticket !== epoch) return;
        if (connected) await connected.read(); else await directory.refresh();
        if (ended || ticket !== epoch) return;
        if (connected) {
          const host=root.ownerDocument.defaultView;
          const update=()=>{ if (!ended && ticket===epoch) showURL(connected??binding); };
          const off=directory.subscribe(update);
          observe=()=>{ off();host.removeEventListener('popstate',update); };
          host.addEventListener('popstate',update);
        }
        // Publish every resource before authored status callbacks can destroy.
        owner=candidate;controller=directory;view=mounted;binding=connected;unobserve=observe;
        candidate=directory=mounted=connected=observe=undefined;
        showURL(binding);
        if (!ended && ticket===epoch) say('Directory is ready.');
      } catch { failed=true; }
      finally {
        cancelViews();
        await candidate?.dispose();
        if (pending === job) pending=undefined;
        if (failed && !ended && ticket===epoch) {
          retry.textContent='Retry loading directory';
          say('Directory could not load. Retry, or browse the resources below.');
          if (!ended && ticket===epoch) retry.hidden=false;
        }
      }
    });
    return job.promise;
  }
  const click = () => { void start(); };
  const retryURL=()=>{ if (!ended && binding) { binding.write();showURL(binding); } };
  retry.addEventListener('click',click);
  urlRetry?.addEventListener('click',retryURL);
  if (urlStatus) urlStatus.hidden=true;
  if (urlRetry) urlRetry.hidden=true;
  retry.hidden=false;retry.textContent='Enable directory';
  say('Browse the resources below, or enable the directory.');
  function destroy() {
    if (disposal) return disposal;
    let finish, fail; disposal=new Promise((resolve,reject)=>{finish=resolve;fail=reject;});
    ended=true;epoch++;
    const previous=owner, previousView=view, previousBinding=binding, previousController=controller, stopObserve=unobserve, work=pending;
    owner=controller=view=binding=unobserve=undefined;
    retry.removeEventListener('click',click);urlRetry?.removeEventListener('click',retryURL);stopObserve?.();work?.cancel();previousView?.destroy();previousBinding?.destroy();previousController?.destroy();
    if (urlStatus) urlStatus.hidden=true;
    if (urlRetry) urlRetry.hidden=true;
    retry.hidden=true;say('Directory is closed. Browse the resources below.');
    Promise.all([work?.promise,Promise.resolve().then(()=>previous?.dispose())]).then(finish,fail);
    return disposal;
  }
  return Object.freeze({start,destroy});
}
load.mjs

import { createRaveldex } from '@vmitsaras/raveldex';
import { configuration } from './configuration.mjs';
import { validateContent } from './content.mjs';
export async function loadResources(contentUrl, signal) {
  const response = await fetch(contentUrl, { signal, cache: 'no-cache' });
  if (!response.ok) throw new Error('Resource data is unavailable');
  const bytes = new Uint8Array(await response.arrayBuffer());
  if (bytes.length > 4 * 1024 * 1024) throw new Error('Resource data exceeds the example limit');
  const entries = validateContent(JSON.parse(new TextDecoder('utf-8', { fatal: true }).decode(bytes)));
  signal.throwIfAborted();
  const engine = createRaveldex(configuration());
  try {
    for (let offset=0; offset<entries.length; offset+=100) await engine.addMany(entries.slice(offset,offset+100).map(entry => ({ id:entry.id,
      text:{title:entry.title,body:entry.body},metadata:{format:entry.format,topics:entry.topics} })), { signal });
    signal.throwIfAborted();
    const base = new URL('./', contentUrl);
    return { engine, documents: entries.map(entry => ({ id:entry.id,title:entry.title,url:new URL(entry.path.slice(1),base).href })), dispose:()=>engine.dispose() };
  } catch(error) { await engine.dispose(); throw error; }
}

# Astro resource-directory starter

Copy this complete static Astro project to build seven explicit public resource pages and an optional filterable directory. Enable the directory, then search `walking resource`: seven pages match, with three on each native result page. Use the resource-type/topic checkboxes, remove selected chips, navigate Back/Forward and follow a real resource link. All browse links work before enabling search and without JavaScript.

import { groups } from './configuration.mjs';
export function validateContent(entries) {
  if (!Array.isArray(entries) || entries.length > 1000) throw new Error('Expected up to 1000 explicit public resources');
  const ids = new Set(), paths = new Set(); let units = 0;
  const string = (value, limit) => typeof value === 'string' && value.length <= limit && value.isWellFormed();
  for (const entry of entries) {
    if (!entry || Object.keys(entry).sort().join(',') !== 'body,format,id,path,title,topics'
      || !string(entry.id,256) || !entry.id || ids.has(entry.id) || !string(entry.title,1024) || !entry.title.trim()
      || !string(entry.body,50000) || !string(entry.path,128) || !/^\/resources\/[a-z0-9-]+\/$/.test(entry.path) || paths.has(entry.path)
      || !groups[0].values.includes(entry.format) || !Array.isArray(entry.topics) || entry.topics.length > 8
      || new Set(entry.topics).size !== entry.topics.length || !entry.topics.every(value => groups[1].values.includes(value))) throw new Error('Invalid or duplicate resource record');
    ids.add(entry.id); paths.add(entry.path); units += entry.id.length + entry.title.length + entry.body.length + entry.path.length + entry.format.length + entry.topics.join('').length;
    if (units > 4000000) throw new Error('Resource text exceeds the example limit');
  }
  return entries;
}

import { createDirectory, connectDirectoryURL } from '@vmitsaras/raveldex/addons/ui/directory';
import { mountRaveldexDirectory } from '@vmitsaras/raveldex/addons/ui/directory/view';
import { groups, labels, settings } from '../configuration.mjs';

// This application owns only owners transferred by load(signal). The view itself
// borrows the controller, and the controller borrows that owner's engine.
export function createDirectorySearch({ root, status, retry, load, urlStatus, urlRetry, urlState = settings.urlState }) {
  let owner, controller, view, binding, unobserve, pending, ended = false, epoch = 0, disposal;
  const say = text => { status.textContent = text; };
  function showURL(connected) {
    if (ended || !connected) return;
    const snapshot=connected.getSnapshot();
    const text=snapshot.status==='error' ? 'Search works, but the address could not be updated. Try updating the search link.'
      : snapshot.issues.length ? 'Some search link values were reset. The current filters are shown.' : '';
    if (urlStatus) { urlStatus.hidden=!text; if (urlStatus.textContent!==text) urlStatus.textContent=text; }
    if (!ended && urlRetry) urlRetry.hidden=snapshot.status!=='error';
  }
  function start() {
    if (ended || owner) return Promise.resolve();
    if (pending) return pending.promise;
    const ticket = ++epoch, abort = new AbortController();
    const job = { cancel: () => abort.abort(), promise: undefined };
    pending = job;
    job.promise = Promise.resolve().then(async () => {
      let candidate, directory, mounted, connected, observe, failed = false;
      const cancelViews = () => { observe?.(); observe=undefined; mounted?.destroy(); connected?.destroy(); directory?.destroy(); };
      job.cancel = () => { abort.abort(); cancelViews(); };
      try {
        if (ended || ticket !== epoch) return;
        retry.hidden = true; say('Loading directory. You can browse the resources below.');
        if (ended || ticket !== epoch) return;
        candidate = await load(abort.signal);
        if (ended || ticket !== epoch) return;
        directory = createDirectory({ engine:candidate.engine,groups,pageSize:settings.pageSize,mode:settings.mode });
        mounted = mountRaveldexDirectory({ root,controller:directory,documents:candidate.documents,groups:labels,debounceMs:settings.debounceMs,
          messages:{label:'Search walking resources',placeholder:'Try maps or weather'} });
        if (ended || ticket !== epoch) return;
        if (urlState) connected = connectDirectoryURL({ controller:directory,host:root.ownerDocument.defaultView,parameters:settings.parameters,history:settings.history });
        if (ended || ticket !== epoch) return;
        if (connected) await connected.read(); else await directory.refresh();
        if (ended || ticket !== epoch) return;
        if (connected) {
          const host=root.ownerDocument.defaultView;
          const update=()=>{ if (!ended && ticket===epoch) showURL(connected??binding); };
          const off=directory.subscribe(update);
          observe=()=>{ off();host.removeEventListener('popstate',update); };
          host.addEventListener('popstate',update);
        }
        // Publish every resource before authored status callbacks can destroy.
        owner=candidate;controller=directory;view=mounted;binding=connected;unobserve=observe;
        candidate=directory=mounted=connected=observe=undefined;
        showURL(binding);
        if (!ended && ticket===epoch) say('Directory is ready.');
      } catch { failed=true; }
      finally {
        cancelViews();
        await candidate?.dispose();
        if (pending === job) pending=undefined;
        if (failed && !ended && ticket===epoch) {
          retry.textContent='Retry loading directory';
          say('Directory could not load. Retry, or browse the resources below.');
          if (!ended && ticket===epoch) retry.hidden=false;
        }
      }
    });
    return job.promise;
  }
  const click = () => { void start(); };

How this example works

Let visitors search a resource library, choose several filters, remove selected choices and reach every matching page. Copy a complete browser or Astro project, replace its explicit public records and adjust a few CSS properties.

Use this directory for persistent resource lists. Choose inline search for simple page results, the documentation modal for button-opened search or the compact header for a few quick page links.

Search walking resource: seven pages match, three per page. Open Filter resources, choose Guides and Safety, then remove a selected chip or Clear all. Counts describe the current matching set, including each group's own selections. Choices within one group combine with OR; different groups and text combine with AND. A zero-count choice stays usable.

  2. Edit the existing .raveldex-directory rule in browser theme.css or Astro src/style.css, loaded after the package stylesheet:

  2. Search walking resource again: seven pages still match. Use Next page to reach every match, change filters, inspect Tab focus and follow a real resource link. Theme changes keep the same query, totals and native order.

Set background, color, muted, border, focus and button colors together when building another palette. See directory controls and styling for the component API.

Mobile filters and URL state

Filter resources is a native disclosure, closed initially at every width. Open/close it with the summary; Close filters or Escape inside it restores summary focus. Resizing keeps its current choice. Removing a focused chip moves to an adjacent chip or the search field; native checkboxes stay in place as counts change.

Both starters explicitly select URL synchronization and push for committed edits/pages. Back/Forward replays query, selections and page without new entries. Use replace for live edits in one entry, or turn URL state off in configuration for an in-memory directory. Unrelated parameters/hash survive. No local search-history store or telemetry is created. Empty searches browse all resources; no-results, initialization failure, native refusal and changed revisions have visible recovery.

Run the copied root/subdirectory build with changed data and CSS. Check every page, filter combinations, zero-result recovery, loading/Retry, Back/Forward, native links, long/RTL labels and dark/forced colors. Scripted keyboard/composition, selected axe and emulated layout results are distinct from human AT speech, physical IME/touch/on-screen keyboards, actual browser zoom, Safari/device support and hosted deployment.
