# RX-4001 evaluation

The native engine's correctness and its usefulness for a documentation query are different observations. This slice evaluates existing contracts without changing the scorer, analyzer, limits, public methods, optional exports or dependencies. A poor lexical or ranking outcome is retained as a finding.

## Correctness and frozen relevance

The installed public package replay passes 345 independent query/page comparisons, 75 mutation operations with 77 source-policy state checks and 1,155 complete query/page comparisons, 438 independent phrase comparisons, 288 exact representation comparisons and ten hand-derived score assertions. The expected analyzer, eligibility, statistical and scoring behavior comes from separately coded full-source references and literal/rational numerical cases. The full existing suite is also rerun; see the [acceptance record](../evidence/RX-4001.md) for its final result and independent review.

The relevance dataset freezes 34 complete allowlisted documentation sections from five files, with hash `8ba88f8c4610a83ee3dcf453ce2434c16e6d2f3af070590f2e220c7bec28244b`. It contains 76 distinct source-authored queries: 70 with known relevant answers and six justified intended empties. Labels and source bytes were frozen before these production rankings. Must-find, acceptable and known-irrelevant labels are explicit. Unlabelled results remain unknown. One evaluator's English technical self-documentation labels are incomplete and do not represent a user population.

## Pinned companion comparison

The explicitly injected LocalSearch checkout is commit `5f334a8ca4f7d9d95b6b731ac539f4b1dda302cb`, using actual MiniSearch 7.2.0. Its current public source/entry hashes and all 344 tracked file identities are checked before/after; no historical pass is imported. Native NFKC analysis and foreign NFC analysis are declared separately. Each complete membership is checked against its own independent source reference.

Seventy-one typed translations have equal complete eligibility. Eleven have different result orders; no score equality is required between the models. Three native Boolean trees and two successful tokenless empty-result contracts have no semantics-preserving companion representation and are marked Not comparable. The [raw comparison](../evidence/RX-4001-comparison.json) records the exact queries, fields, scalar filters, strict phrase/count meaning, source retention, pins, output differences and unsupported behavior.

| Equal-membership subset only | Top-1 | Top-3 | MRR@100 | Macro judged Recall@10 | Intended empties |
| --- | ---: | ---: | ---: | ---: | ---: |
| Native | 49/67 | 55/67 | 0.7736 | 0.6863 | 4/4 |
| Companion/MiniSearch | 48/67 | 55/67 | 0.7662 | 0.6863 | 4/4 |

These are the same source labels over a restricted subset, with ten unintended empties in each model. They do not establish an overall winner. The companion always retains full originals and computes mandatory original evidence/snippets even with empty `returnFields`; native ordinary results do not do that work. Native arbitrary Boolean scoring, alternative weighting, numerical facts, cooperative loops and source-free operation do not have identical foreign counterparts. Foreign upstream retrieval is synchronous and lacks the native numerical decomposition.

## Reproduce

Install the existing tooling and verify correctness before measuring. Prepare one local installed tarball consumer, then use the absolute directory printed by the prepare command:

```sh
npm ci
npm run check
npm run evaluate:prepare
rx4001_consumer=/absolute/path/printed/by/prepare
npm run evaluate:correctness -- "$rx4001_consumer" /tmp/raveldex-rx4001-correctness.json
npm run evaluate:relevance -- --consumer "$rx4001_consumer" --output /tmp/raveldex-rx4001-relevance.json
npm run evaluate:comparison -- "$rx4001_consumer" /absolute/pinned/LocalSearch /tmp/raveldex-rx4001-comparison.json
npm run measure:costs -- "$rx4001_consumer" /tmp/raveldex-rx4001-costs.json
npm run measure:browser-costs -- "$rx4001_consumer" /tmp/raveldex-rx4001-browser-costs.json
```

Run timing commands sequentially without another automated test/build/benchmark. The foreign checkout argument is explicit and read-only; routine CI does not depend on it. Local packing/installing does not publish. See the [cost method](RX-4001-cost-method.md) for fresh owners versus warm processes, repetitions, work instrumentation, default bounds, selected graphs and interpretation. Memory, physical presentation, assistive technology and the browser qualification matrix remain RX-4002 observations.
