Advanced demo settings

Changing a setting rebuilds the collection, keeps your query and resets the category and page.

Destroy interface removes the controls. Reinitialize search rebuilds the collection and brings them back.

Use the controls

Press Tab to move between controls and result links, or Return to submit from the search field. Choose a Document category to narrow matches and All to clear it. Changing page shows more results without changing the total. These updates keep focus on the control you used.

Open Inspect results to see which terms matched and how scores were calculated. Close Inspector or press Escape to return focus to that button. Snippets are short excerpts; follow a result link to read the complete guide.

Try source provide to complete the final word, or unmatchedword for an empty result. Choose a sample query to recover. Advanced demo settings let you compare final-word prefix, exact-word and strict adjacent phrase searches, source reanalysis, stored positions, direct execution and one module worker.
