Changing a setting or restarting keeps your query, clears the category and returns to the first page.

Original text checks phrases against the guide text; saved word positions keep that information in the index. This page and Background worker use the same search results. Match a phrase requires the words in order, next to one another.

Stop search removes the live controls. Restart search brings them back with your query, no category filter and the first page.

Use the controls

Press Tab to move between controls and result links, or Return to submit from the search field. Choose a Document category to narrow matches and All to clear it. Changing page shows more results without changing the total. These updates keep focus on the control you used.

Open Inspect results to see the original matching excerpts and how scores were calculated. Close Inspector or press Escape to return focus to that button. The result overviews are short; follow a link to read the complete guide.

Try source provide to complete the final word, or unmatchedword for an empty result. Choose a sample query to recover.
