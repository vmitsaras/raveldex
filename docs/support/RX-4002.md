# RX-4002 qualification scope and remaining observations

RX-4002 preserves the accepted [verification plan](../planning/VERIFICATION_PLAN.md) and all seven task criteria. It adds observations of the existing native runtime; it does not change public exports, analyzer/ranking semantics, limits, runtime dependencies, snapshot qualification policy, or the private package's release status.

## Browser scope

The reproducible installed-package browser matrix and its exact versions are recorded in [browser notes](RX-4002-browser-notes.md) and the [task evidence](../evidence/RX-4002.md). The selected automated environments exercise public imports and declared flows. A passed fixture covers those flows, versions and configurations; it does not promise every OS, every browser release, or all Unicode inputs.

Playwright's patched Firefox and automated WebKit builds are identified explicitly. Automated WebKit is distinct from a tested Safari/OS combination, as described in [Playwright's browser documentation](https://playwright.dev/docs/browsers). Synthetic composition, browser role/name checks, keyboard automation and axe results are distinct from OS IME, actual speech and physical input observations.

The separate [native facet continuation](../evidence/RX-4002-facets.md) observes Guide selection and clearing after a recorded typeahead pause in WebKit 26.5 and Chrome 155.0.8059.40. It preserves the historical broad matrix and makes no new engine/storage/resource, installed Safari, AT or physical-input claim.

Ordinary and worker analyzer profiles remain `unqualified`. Native browser/worker snapshot import remains unavailable; the source snapshot path reanalyzes receiving text. A matching bounded Unicode fixture or fingerprint never promotes a host to all-Unicode or native-snapshot portability qualification.

## Memory and resource scope

The [memory method](../evaluation/RX-4002-memory-method.md) defines the measured realm/process, harness baseline, garbage collection, cleanup, repetitions and instrumentation. Measured reachable self-size, recorded-graph node-cut effects, process heap/RSS and observed maxima retain their own meanings. The offline node cuts use existing dumps and remove every alias to a selected node; they do not establish actual V8 collection or allocation peaks. Encoded bytes and logical work/object counts remain separate. A scope that the method cannot isolate stays Blocked; it receives no guessed allocation total.

All resource experiments stay at or below 10,000 admitted records and the unchanged work/deadline/transport ceilings. Typed bounded refusals remain operation outcomes. A successful 10,000-record build does not promise that every subsequent snapshot/recovery/query combination succeeds under the same ceilings. The 15 KiB gzip target remains unchanged and its existing miss remains visible.

## Required observations before completion

[The exact-tool and physical checklist](../accessibility/RX-4002-manual-observations.md) preserves the required query/results/status, error/retry, filter/facet, Inspector and worker recovery observations. Installed VoiceOver/Safari and hardware inventory are not passes for those observations. Physical device/display/input conditions and actual outcomes must be supplied by an evaluator or a suitable physical instrumentation method.

No narrower release claim is proposed, no acceptance criteria are removed, and no missing proof is waived. RX-4003 remains dependent on completing RX-4002. The local private package may continue to be used within its explicitly observed scope; publication, release tags, visibility and deferred N5 work remain separate owner actions.
