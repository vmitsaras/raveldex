# Applying the N10 engineering verdict

The [scoped verdict](../evaluation/RX-9007.md) supports lower observed wall time for the measured native N9 workloads versus pre-N9, with explicit CPU costs and small-update regressions. Accepted N9 and measured current are the same implementation control; this is no further optimization or universal latency/capacity guarantee.

| Application concern | Use the evidence this way |
| --- | --- |
| Query responsiveness | Selected Node and direct/worker browser queries improve under the recorded source/body recipes. Exact totals still require the complete eligible work; a smaller page is not an early-stop query. Keep typed work/deadline/expansion failures distinct from empty results. |
| Frequent updates | Larger selected update windows improve in wall time, while process CPU remains mixed. Preserve the four N100/core-only wall regressions and seventeen CPU regressions when assessing the actual workload. `addMany` is one public call; sequences of replacements/removals are separate commits. |
| Recovery and persistence | Require retained source for every schema text field. Use the [qualified envelope](../evaluation/RX-9006-scoped-20261108.md), not a blanket 10k-document threshold. Real-docs/high-cardinality 10k exports can refuse even with 60s; no dependent restore succeeded when export failed. |
| Cancellation or lost delivery | Authoritative precommit failure preserves old state, but an unknown/expired worker receipt does not establish rollback. Reconcile the captured operation; if the owner/session cannot establish the outcome, use an explicit replacement owner and authoritative data. Avoid blind write retry. |
| Worker placement | A worker changes execution location while preserving native query/work contracts. Browser timing boundaries do not isolate IPC or establish browser CPU/heap savings. |
| Capacity, tails and memory | Source/positions/options/text volume matter separately from record count. Sparse cells have no p95; selected correlated tails are descriptive. Bundle gzip, encoded snapshots and harness process samples are not retained/peak engine heap. |

Keep existing public limits, receipt ownership and source/native format boundaries. The verdict establishes no native Safari/Firefox/mobile performance envelope, broad device/AT acceptance, package release or new version. N11 consumer styling/interaction and its reported AT/zoom observations retain their separate evidence scope. [Existing workload/ownership guidance](RX-8011.md) and [compatibility](../api/COMPATIBILITY.md) remain applicable.

Historical raw failures and incomplete recovery data are retained. No new benchmark or engine change was needed to reach this conclusion.
