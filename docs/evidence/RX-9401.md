## Findings and changes

Current installed source, rather than the stale pre-release snapshot, reproduced
a visible unavailable Retry search action after successful recovery/reset. New
inline and modal browser tests failed on that exact assertion before the repair
([inline](N14_UI/inline-red.log), [modal](N14_UI/modal-red.log)).

The shared presenter now retires an unavailable retry only after native focus
leaves it; repeated activation cannot issue another query. Empty outcomes retain
their query/filter guidance without an empty Results heading/list. Feedback has
bounded padding and a visible empty/error border using existing component tokens;
tighter heading/result spacing leaves more reading area in both surfaces. The
polite status region stays exposed. Public CSS overrides and DOM hooks remain.
