## Supervision and method boundaries

[The supervisor](../../../../bench/n10/host-recovery-supervisor.mjs) owns the controller's POSIX process group and at most one acknowledged browser-wrapper group. It uses monotonic context/total deadlines, complete-watchdog admission before the closing cutoff, bounded startup/validation/teardown/report waits, SIGTERM then SIGKILL escalation, actual PID/parent/group identity checks and bounded IPC/log/event retention. Non-regular pin files reject before reading. Existing output directories remain untouched. Inner report.json and supervisor.json are distinct, and artifacts are acknowledged at existing capture points rather than buffered until context end. A watchdog or supervisor interruption records incomplete orchestration with nativeOutcome null.

Playwright's detached Chromium group needs a named-only launcher. The generated executable wrapper, module and real executable are hash-bound; the wrapper receives a live ownership acknowledgement before the real executable can start. The real executable inherits the registered group and protocol descriptors 3/4. Short fake Node tests verify those descriptors and reclaimed descendants. If a launcher was created but its group was never acknowledged, cleanup remains Unconfirmed and acceptance fails. The supervisor does not guess orphan PIDs or kill by global process name.

The named browser path uses launchServer plus a browser connection rather than legacy launch. This changes startup, transport, allocation and warming outside selected native windows. It is part of the separately named method and remains unqualified with actual Chromium in this slice. Native Node/browser bundle bodies, selected operation windows, public calls/options, branch-required pages, source/offset checks, receipts, aborts, later writes and disposal logic retain their previous bytes.

Supported containment is for this controlled POSIX harness, not hostile executables. Bounded API waits and signal attempts are not a hard operating-system real-time guarantee under loader, scheduling, filesystem or signal-delivery stalls. A persisted supervisor elapsedMs is sampled before its own final terminal write; the API rechecks the clock after that write and returns/throws failure on late settlement, attempting incomplete/overrun witnesses. The gate rejects those witnesses. A terminal file from a failed/interrupted invocation alone is not acceptance; retain the actual API/CLI outcome. No physical durability, heap/GC or universal process-reaping guarantee is inferred.
