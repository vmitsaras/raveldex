Implementation complete: `/addons/proximity` exports `createProximity`, `PROXIMITY_POLICY` and readonly payload/options types. Core adds explicit `ordered-token-groups` to the existing refinement protocol; it owns capture, one-time analysis, canonical groups and immutable groups/maxGap context. The optional module shares authoritative original-position validation and uses bounded unions/reachable endpoints, without enumerating Cartesian paths. Existing strict phrase contexts and evaluator/scorer paths remain intact. Ordinary imports select no proximity module or state. The package remains private `0.1.0-rc.0` with no runtime dependency or lockfile change.

Range/snippet projection is deliberately outside this slice: existing projection assumes adjacency, so a query containing any ordered leaf rejects a requested token range/snippet projection with `MISSING_CAPABILITY`, including failed/negative branches and empty IDs. Inspector numerical facts remain supported. This explicit limitation avoids fabricated adjacent-phrase highlights; no UI/announcement policy changes follow.
