## Scope and public contract

The optional `/integrations/localsearch` entry converts canonical format-1
companion source `Uint8Array` snapshots into owned frozen native
configuration/records and separately labeled historical provenance. It exports
the converter, `MigrationError`, fixed diagnostic codes and readonly types.
The seven-method core facade, native analyzer/ranking/limits, optional provider
selection and runtime dependencies are unchanged. Rebuild uses a new native
owner; conversion never mutates a borrowed owner or storage.

Foreign comparison support is explicitly injected development code outside the
runtime compile/export/package graph. No legacy search facade, fallback engine,
opaque-index importer, automatic namespace migration or publication is added.
