# RX-2006 — Native DOM UI, Inspector, and documentation pilot

Date: 2026-10-07. Local branch: `codex/rx-2006-native-ui`; base `1a2df91`. Scope: one optional native DOM presentation slice and its real offline-installed documentation consumer. Core algorithms/methods/limits/model are unchanged; no worker, storage, deferred N5 work, publication, push or remote tracking write is included.

## Implementation and public contracts

`/addons/ui` exports `mountRaveldexUI` and readonly UI options/handle/document/facet types. CSS is exported separately at `/addons/ui/styles.css`; JS has no CSS injection or startup DOM/timer/network access. Separate DOM compiler projects preserve the existing DOM-free core/declaration fixture. The package remains private ESM 0.0.0, with zero runtime dependencies. Pinned development-only Playwright Core 1.61.1 and axe-core 4.13.0 support required real browser and automated accessibility checks. Existing TypeScript 7.0.2/esbuild 0.28.2 remain unchanged. CSS alone is marked side-effectful for bundlers.

Mount captures bounded caller navigation/options, enhances a root with a labeled native search form, conjunctive string category filters/facets, exact pagination, safe original snippets/marks, status/error/retry and a native modal Inspector. Main, snippets and Inspector agree on the admitted page limit and revision; only one evidence extension is requested per operation. Request cancellation and obsolete-presentation suppression are independently observable. Composition pauses interim requests, submit flushes debounce, controls retain focus and Inspector close/Escape restores its opener. Duplicate mount returns the existing handle. Destroy removes UI listeners/timers, aborts requests, suppresses late replies and restores exact authored Node identities. The engine is borrowed and remains searchable until its application disposes it.

Bounds: 10,000 unique navigation records; IDs/titles/URLs 256/1,024/2,048 UTF-16 units, combined navigation units 4,000,000; eight string facets, 32 snippet fields; pageSize 1–100/default5, debounceMs 0–2,000/default150. Human-facing names require non-whitespace text. HTTP(S), relative and protocol-relative HTTP(S) links are allowed without credentials; javascript/data/file URLs are rejected before DOM mutation. Requested capabilities fail visibly rather than fallback. Initial page size must fit any stricter borrowed-engine ceiling unavailable through its public interface; final pages narrow to known remaining hits/navigation entries. No typed query-language parser or new scorer is introduced.

`examples/docs-search/` consumes public installed imports and the existing explicit five-file/34-section allowlist. Source and stored positions/original offsets rebuild the same corpus; originals remain explicitly retained for snippet display. Application transitions serialize old-owner disposal, abort in-flight indexing, preserve query text and suppress stale mounts. The local preview serves only generated allowlisted artifacts. Its corpus fetch stays local; source-link navigation is an explicit user action.
