## Implemented boundary

Internal TypeScript ESM sources implement field-aware frequency dictionary/postings, reverse document frequencies/field lengths, canonical equality metadata and complete exact normalized-term eligibility. [IndexConstruction](../../src/core/index/construction.ts) captures each bounded batch before returning its cursor, completely validates content while consuming shared `basic-v1` analysis, and exposes one frozen revision-0 root only after finalization. Duplicate IDs in a captured batch reject with `INVALID_RECORD`; conflicts with previously staged IDs reject with `ID_EXISTS`. A failed or abandoned append/finalization invalidates and releases staging. No searchable partial root is returned. Callers must exhaust cursors; these are private integration seams, not the public Promise API.

[Directory layout](../../src/core/index/directory.ts) uses 256 logical slots, lazy slot pointers, prototype-safe data buckets and bounded UTF-16 FNV-1a hashing. Completed objects are deeply frozen. Frequency-only roots retain IDs, schema/configuration, canonical metadata, reverse frequencies, token lengths, logical original input-size counts and dictionary/postings statistics. They retain no original record text, token occurrence/value boundaries, positions, offsets or optional participant roots. Source retention still requires an explicitly installed future provider; this slice creates none and rejects unsupported registrations.

[Exact lookup](../../src/core/retrieval/exact.ts) takes a normalized dictionary term and optional nonempty unique selected declared fields; it unions every matching posting across field/value aggregates and returns a frozen complete ID array. It makes no ranking/order/page promise. Full typed/raw query evaluation, prefix expansion, BM25, public engine/factory/package consumer, incremental copy-on-write mutations, coherent revision publication, queues, cancellation/deadlines and host yielding remain RX-1003–1006 work. No public contract or package export changed.

## Failures, repairs and independent review

- Test/evaluation defects: the initial hand count of logical text code units was 32; manual per-record sums are 13 + 14 + 7 = 34. Corrected the expected count. A broad JSON keyword assertion wrongly matched the legitimate schema `text` key and normalized term `source`; replaced it with exact structural checks of retained document/reverse/term/posting records. Focused suites passed after those corrections.
- Implementation defect identified independently: charging canonical metadata output alone omitted original duplicate entries processed by `Set`. Reviewer probe reported identical append work (7) for one versus 128 Boolean values. The repair charges original field/value inputs before canonicalization (including string code units), then output separately. Regression verifies 127 extra units for 127 duplicate Boolean entries, string duplicates add scan/input units, and a lowered budget rejects before a root can be returned. Focused index suite passes 11/11 after repair.
- Independent review inspected raw specs, sources and tests; built/ran the 35-test focused suites and typecheck; separate probes compared 80 corpora / 2,344 exact field lookups and statistics, exercised 97 append/finalize abandonment checkpoints and 1,000 same-bucket IDs. Initial verdict was Changes required for metadata accounting only. After repair the reviewer rebuilt, passed 36/36 focused tests and 149/149 full checks, reran the diagnostics and deep-compared the entire JSON with the saved artifact (exact match), independently confirmed the 444 oracle comparisons, and reviewed the resource/public-contract claims. Post-repair probes pass 80 corpora, 2,344 lookups, 101 abandonment checkpoints (four extra yielded metadata steps) and 1,000 collisions. Metadata append costs are now 9 versus 136 units; finalization is 3 for both. Final verdict: **Ready**, no remaining material findings.

Native reflection/enumeration (`Reflect.ownKeys`, `Object.keys/entries/values`), freezing, bounded hash/string operations and canonicalization are indivisible host primitives. Enumeration can allocate a complete bucket/key list before the next charged step; collision buckets may be corpus-sized. Admission entry bounds limit captured structures but do not bound all allocation/cost of rejected input reflection. This slice does not claim interruptibility, cancellation latency, heap/peak bounds, constant-time changes, package size, public search readiness or relevance.
