# RX-6002 — Inline controls, paging and theming

Date: 2026-10-30. Implementation, scoped automated verification and local documentation/planning synchronization are complete. The next task remains a separate slice.

## Implemented scope

- Extended only the optional inline preset with explicitly selected snippet fields and simple string facets, five-hit batches, bounded Load more and complete Next/Previous window continuation. Default visible cap is 100; configured caps are integers from page size through 1,000. Nonmultiple caps do not skip matches.
- Main, accumulated and snippet result revisions/IDs/order/scores/totals are checked before committing results or facet counts. Revision changes and failed evidence clear the attempted presentation and offer a first-window retry retaining query/selections. No live index mutation subscription or implicit host fallback is claimed.
- Facets use core scalar equality plus an explicitly installed facets capability. Native conjunctive counts include their own active filter; projections remain bounded and selected undisplayed values remain recoverable. Filter-only browsing is explicit; clear resets text and selections. No structured-filters registration is required for these equality controls.
- Snippets use original source slices and returned UTF-16 highlight offsets, one new batch at a time (at most 100 IDs), including empty ID requests so missing requested providers are never silently ignored. Omission counts and limit/oversized-match notices stay visible.
- New message keys are optional publicly, preserving original complete 12-key bundles; internal defaults are complete. Consumer diagnostics remain off; legacy UI is the explicit developer-oriented presentation. Expanded scoped CSS supports facets, marks, navigation, state, density, dimensions and host-selected themes.
- Core, dependency metadata/lockfile, legacy UI/query/render helpers, worker protocol, static artifact schema and RX-6001 evidence remain unchanged. Full installed browser/Astro starters are RX-6003, not this slice.
