## Implemented boundary

`MutationOwner` is a private serial transaction owner around a coherent frozen initial `IndexRoot`. `capture` owns bounded records/IDs/options under one admission counter; `execute` selects the current root when its cursor starts. Add/addMany/replace/remove/clear prepare changes, update field/corpus/dictionary/posting statistics by deltas and seal touched directories. A transaction cache copies each touched document/dictionary/posting bucket once and shares unchanged buckets/records. Old reverse frequencies suffice for removal; original text is absent in frequency-only mode.

The prepared root includes every installed trusted participant root. Participants consume immutable changed inputs/old roots and yield charged preparation work before publication. The final stop check follows the final yielded step. A single non-yielding assignment publishes all state and the incremented safe-integer revision; no participant callback executes afterward. No-ops retain the same root/revision and skip preparation callbacks. Aborts, rejected inputs, phase/participant faults and abandoned cursors preserve the old root and release the active-owner lock. Identical replacements deliberately commit. Requests cannot be replayed or executed by another owner.

One mutation work-v1 budget covers input/content analysis, reverse subtraction, pointer/bucket copies, updates, sealing and participant work through the final commit check. Mutation signals are checked at work/phase boundaries and immediately before commit. Public promises, FIFO admission/overflow, search cancellation, monotonic deadlines, disposal and actual host task yielding remain RX-1005. Public package consumption remains RX-1006. The new participant/control/diagnostic seams are internal; no public query/options/result contract changed, and there is no installed public source/positions registration yet.

Expected scores use the independent source formula and successful-branch participation. Complete hit IDs/order/totals are exact; numeric score tolerance is max(1e-12, abs(expected) × 1e-12).

The largest yielded work charge in these rows is 24; this is not interruption latency.

Native Object.keys/freeze/hash/normalization/allocation are bounded indivisible primitives, even when surrounding owned loops resume. Collision buckets can contain many admitted entries; correctness is checked with same-slot IDs and common terms, without an average-size or constant-time guarantee. No peak/retained-memory, timing, physical-paint, package-size or worst-case-capacity qualification is inferred from these counts.
