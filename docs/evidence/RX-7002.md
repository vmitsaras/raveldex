## Defects found and repaired

Independent review identified three initial source-only concerns, repaired before an old-runtime reproduction: pending startup was checked after owner publication and could lose initial-query deduplication; cleanup jobs could be removed before awaited disposal; and the modal preset's persistent trigger listener could bypass later wrapper refusal. Pending work now remains authoritative through cleanup, and the application owns its explicit button admission. These are not relabeled reproduced old bugs.

Actual Chrome/WebKit probes then reproduced reentrant focus handoffs reopening an older query after a newer handoff/close, or after a newer invalid request refused. A per-handoff epoch invalidates every older invocation, including refused calls, with raw-query/identity/lifetime checks around close, mount, focus, open and feedback callbacks. Native dialog API/opening failures formerly escaped as page errors while feedback still said ready. Local recovery now preserves the owner/header/full route, reports a readable message and permits a genuine same-owner retry. Successful retry clears only the obsolete handoff failure notice; malformed initial-link guidance remains. Dark outer focus and modal/error palettes are scoped separately from query behavior.

Fresh installed pointer tests exposed an existing dropdown defect in both ordinary and post-loading-retry flows. Trusted pointerdown/mousedown hit the actual anchor with the document focused and no scroll. Native input blur reported that connected anchor as `relatedTarget` while `document.activeElement` temporarily became BODY. The old blur microtask closed and removed the anchor before pointerup, which reached underlying MAIN and produced no click/navigation. The new runtime regression recorded **0/1 passing** against old compiled source, with an actual navigation timeout. The bounded repair trusts an owned native related target; null/outside blur keeps the existing guarded dismissal. No click interception, preventDefault workaround, synthesized navigation, engine/API/ranking change or alternate popup is added. The task manifest records these two additional affected runtime/test paths.

Final source-stable independent probes pass **28 assertion groups** across Chrome/WebKit: reentrant handoffs, native-dialog refusal/retry, lifecycle/dark focus and trusted plain-pointer navigation in standalone and actual wrapper flows. The full installed dropdown suite passes **25/25 in each Chrome, Chromium and WebKit**, including ordinary blur dismissal, the new pointer regression, editing/composition, existing modified-link baseline, native AX relationships where available, stale callbacks, ownership and no-space recovery. Review found no remaining actionable issue in its stated scope.
