## Managed recorder and calibration

The fixed event tape is replaced with a lossless capped unsigned-varint stream, a fixed 65,536-byte native stdio buffer and five separately bounded native extent maps (up to the declared cap per map). This storage is observer overhead outside the managed metric. Exceeding a map/file bound, losing records, unsupported events or abort invalidates the entire window and leaves all derived metrics null. An IO failure or nonzero Stop status disqualifies the window regardless of any written footer; accepted pilots require both status 0 and a complete, independently replayed valid stream.

Exact internal collection begin/end hooks surround `PerformGarbageCollection`; public GC callback reentry/suppression is not used to invent cycle identities. The recorder freezes pre-GC tags, stages moves, removes overwritten source/destination addresses and intersects the resulting tags with a full non-filler heap census after collection. The census obtains a safepoint and completes sweeping/heap iterability, perturbing collection scheduling. It is an occupied-object census, not a root-liveness or retained-memory analysis. A size change during GC is supported only when its whole old extent is disjoint from both frozen and moved monitored tags; tracked/partial layout changes remain unsupported.

The measured quantity is **new monitored managed occupied extents at mutator allocation/size-change frontiers and completed-GC checkpoints**. It includes host/promise/admission/harness allocations and unreachable objects awaiting collection. It excludes preexisting objects, collector copying overlap, external/native backing and OS/process physical peaks. It is not exclusively engine staging or collector-retained data; the baseline is not subtracted.

Six bounded V3 control children exit 0. Independent raw checks establish unmonitored preexisting objects across movement, full new held/dead array coverage, omission of the dead array from moves and post-GC census, surviving movement through minor/major collection, an exact 98,776→80-byte elements shrink, and 2,549 reused birth addresses after collection. The two accepted GC streams contain 104,209 and 423,590 events over two/eight cycles. Async/no-GC/shrink controls pass; map/file caps, existing-file preservation, unsupported flags and natural abort retain their actual outcomes. The file-cap negative control records 106,043 events out of 300,058 attempts and exposes no prefix peak. Parent-authored replay reconstructs the quantities independently using the previously tested AVL index; four new literal stream tests cover overwritten destinations, preexisting moves, deaths, shrink, loss/scope tampering, unsupported tracked GC shrink, overlap and truncation.

A finite overhead experiment contains 16 alternating runs: four recording-on and four off for each of no-GC and GC loops. It reports raw timings and separate Stop costs. GC census/stream/map overhead is material; these tiny noisy controls do not establish product latency or a population overhead factor.

## Actual browser message buffer lifetimes

The native observer uses the same byte-verified cached HeadlessChrome 153.0.8010.12 executable as the prior controls, not the owner's installed browser. It records finite LLDB breakpoints in the shared serializer allocation/growth-copy paths and adds the actual `SerializedScriptValue` destructor/final-free call site. PID, Mach-O UUID, exact code bytes, trace-proven main/worker OS thread IDs, distinct isolate IDs and the dedicated-worker target/URL bind the selected process and peer. Raw entry/return records include call IDs, parentage and PC/SP/LR values; birth IDs protect against address reuse.

A strict version-specific decoder reads at most 256 bytes from a known tracked synthetic buffer, reconstructing the unchanged protocol/session/request/operation/kind prefix. It stops after the `payload` or `value` key without reading that value. This deliberately adds bounded metadata reads to the earlier observer. Native arguments/results and actual public worker envelopes are unmodified. The registry remains armed across checkpoints and is bounded, including bindings, windows, threads and pending calls. Final-free retirement requires the matching active destructor owner, pointer, allocation birth and returned native call.

Its 16 native message buffers match all four JavaScript send/read metadata edges, renderer PID, sender thread and actual worker peer. The last native checkpoint label also contains later prior/restore/search/dispose operations; exact prefix identities, rather than an exclusive label interpretation, bind them.
