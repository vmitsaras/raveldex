## Result and scope

All five galleries now share `ExampleShowcase.astro`: a short introduction,
clear full-page preview link, family navigation and the real installed demo
appear before setup/reference detail. The original inline gallery placed its
iframe at y=875px in a 720px viewport; the new regression verifies that all five
iframes start before y=630px at 1280×900. Technical introductions remain in a
normal disclosure below the preview. Starter downloads and exact sources remain
available, with clearer setup actions.

All eight browser/Astro starter projects carry self-contained matching themes:
neutral surfaces, readable result spacing, blue focus/links, clearer controls,
recovery states and responsive layouts. Directory/cards and dropdown retain
dark/forced-color support. Inline/modal retain their authored light theme and
forced-color handling. Browser/Astro inline, modal and directory CSS pairs are
byte-identical. Shorter facet helper messages preserve the bounded count and
omission placeholders. Records, IDs, destinations, query semantics, native
keyboard models, URL state and lifecycle logic remain unchanged.

Three disjoint workers implemented inline/modal, dropdown and directory/cards.
The parent owned shared galleries/build inputs, integration, evidence and final
checks. A separate read-only reviewer found concrete customization/contrast
defects and reviewed the repairs. [Review and disposition](RX-9701/review.md).
