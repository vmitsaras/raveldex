## Implemented public boundary

`/addons/inspector` exports `createInspector`, `exportDiagnostics` and readonly Inspector/request/source/configuration/resource/diagnostic/native fact types. Factory options `{id?,sourceFields?,maxFacts?,maxWorkUnits?,maxOutputEntries?}` install `inspector` v1 evidence without a participant or retained index. Search requests use `extensions.inspector={ids,maxFacts?,expectedRevision?,sourceFields?}`; at most 128 unique IDs, including zero, further narrowed by core maxDocuments. One complete selected trace per operation; multiple evidence requests fail INVALID_OPTIONS. Core facade remains seven methods/three runtime exports; ordinary result keys stay unchanged.

Data reports selected actual decisions/arithmetic, eligibility/page-local placement, revision/model/configuration/logical counters and explicit unknowns. Source defaults not requested; enabled selected originals are validated at the same execution-start revision before traversal even with no IDs/matches. No historical roots are retained. Successful work is `work-v1`, scoped `before-evidence-projection`, including collection/preparation and excluding output/final delivery. Failed/cancelled/overflow operations return sanitized typed errors without a partial successful explanation.

Complete facts default to 4,096 header-inclusive entries. Module work defaults to 10,000,000; complete structural output defaults to 16,384 entries, narrowed by factory/core bounds, depth 16, and independent 262,144 aggregate original UTF-16 key/string units. Not every 4,096-fact request can fit smaller structural/text caps. Output copy/Unicode/source validation is charged/resumable; core operation and registration budgets/checkpoints/stop precedence still apply. Trusted evidence capture/select/prepare/finish handles receive immutable explicit views and only declared provider roots, never a mutable core root/owner/scorer; callbacks remain trusted and unsandboxed under protocol v1. One registration cap aggregates its implemented refinement/evidence cursors, including repeated leaves. Parsing/projection/source/serialization stays optional.

`exportDiagnostics(data,{includeFacts?,includeSource?,maxCodeUnits?})` returns `{json,complete,omitted}`. Default is configuration/resource metadata only. Explicit facts include IDs/canonical query; explicit source includes only already-selected source, separately from facts/documents. Escaped JSON including the envelope defaults at 262,144 UTF-16 units, reducible. If complete selected sections cannot fit, facts-first whole sections are omitted with identical markers inside parsed JSON; unfit metadata fails. This synchronous utility safely owns/validates already bounded data and runs no engine/host/persistence tasks.
