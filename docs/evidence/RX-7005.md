## Delivered behavior

The optional `/addons/ui/directory/cards` entry exports `mountRaveldexDirectoryCards`, captured readonly display/presentation types and a handle with base search/clear/destroy plus synchronous set/get presentation. Required ID/title/URL records can include bounded plain-text excerpt, category, breadcrumb, localized date, four named fields and validated image/alternative/dimensions. No arbitrary renderer/template, new engine/provider, artifact format, sort or commerce behavior is introduced. CSS is explicit and separate from the base directory stylesheet.

List/card/grid and compact/comfortable/image changes preserve native query/filters/selection/page/totals/IDs/order and existing title-link Nodes/focus, without a query or History write. Results remain ordered lists and ordinary links. Images start off, use native lazy/async/no-referrer behavior only for the displayed page after explicit opt-in, reserve authored dimensions and recover informative failures without clipping their alternative meaning. Decorative failures stay silent. Disabling/teardown removes image callbacks; borrowed controller/engine ownership and authored/foreign DOM protections remain intact.

The complete [14-file browser starter](../../examples/cards-browser/README.md) maps explicit metadata and two authored local SVG assets, generates seven real destination pages and supplies native layout/density/image controls, no-JavaScript browse links, URL recovery, loading/Retry and ownership-safe disposal. The [gallery](../../site/Cards.astro) publishes exact source/archive downloads, an actually installed preview and a CSS recipe. A private fixed-presentation seam shares existing controls without importing the rich renderer into the baseline entry. No static artifact extension is needed.
