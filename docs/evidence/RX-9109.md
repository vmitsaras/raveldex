7 November 2026. Baseline HEAD `0d18463` plus accepted uncommitted RX-9104–RX-9107. This slice changes documentation/decision tracking only; previous work and raw evidence are preserved. No commit/push, remote tracking mutation, deployment or publication occurred.

## Decision delivered

The [source-verified native content guide](../api/RESULT_CONTENT.md) adopts **keep-current**: optional query-derived inline/modal snippets or section context stay separate from authored rich-directory metadata. Its five-surface matrix covers titles/destinations, source labels, excerpts, matching snippets/highlights, section links, category/breadcrumb, dates, fields and images. Native documentation/application/catalogue scenarios choose a supported surface rather than copying a competitor layout.

The guide records actual rendering order, source/display ownership, strict basic record projection, mutually exclusive snippet/maps options (including an explicit empty snippetFields array), null section excerpts, map/revision/refusal distinctions, safe text/URL admission, bounded metadata, image opt-in/retention/request/failure limits and teardown costs. Informative enabled images precede card titles in DOM; they are not merely repositioned visually. No new renderer callback, field, provider, side index, automatic image request or public API was implemented.
