## Public behavior and boundaries

New optional `/addons/filters` exports `createFilters({fields,id?,maxWorkUnits?})` and readonly numeric/set payload types; default ID `filters` provides `numeric-range` and `set-membership` v1. Leaves use existing `{kind:'extension',capability,version:1,payload}` envelopes. Configured fields are declared metadata; known disabled query fields fail `MISSING_CAPABILITY`, bad payload/type/schema fields fail `INVALID_QUERY`, and resource caps fail explicitly. Filters never supply lexical groups or change corpus statistics.

New `/addons/facets` exports `createFacets({fields,id?,maxWorkUnits?,maxDistinctValuesPerField?,maxBucketsPerField?})` and readonly request/result types; default ID/provider `facets`. Request `extensions.facets={fields:[{field,limit?,missing?}]}` selects 1–8 unique enabled string fields. Configured non-string fields fail creation; malformed requests fail even without candidates. Counting/output defaults 10,000/100 narrow only; request output default 20, valid zero, optional missing false. Every qualifying record is counted under its current complete query, including own selections. Result fields preserve request order and contain tagged buckets, `distinctValueTotal`, `omittedBucketCount`. Output projection never permits partial candidate traversal. Ordinary hits/total/model/completeness/revision and seven-method facade stay unchanged.

Trusted metadata handles add bounded admission `capture` and resumable predicate/aggregation roles. Core enforces manifest/handle shapes, finite safe reported payload/output counts and declared/core ceilings. First-party optional capture deeply owns/freezes plain finite JSON without invoking getters; shared structural admission and key+string UTF-16 caps apply. Payload depth 16 is separate from Boolean AST depth. Deferred Unicode/type checks finish before document traversal. Output deeply owns/freezes plain data with actual structural accounting (object properties plus array slots/length); eight maximum value-bucket fields use 3,250 entries under the 8,192 manifest ceiling and stricter core admission cap. One registration work budget covers every prepare/test/add/finish cursor, aliases and combined roles. Contexts expose immutable schema/payload/revision/metadata with no owner/root/scorer. Trusted callbacks remain unsandboxed, as specified. Optional parsers, evaluators and counters never enter core imports or retained side roots.
