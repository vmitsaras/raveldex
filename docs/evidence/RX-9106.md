# RX-9106 — Discoverable keyboard guidance

7 November 2026. Starting HEAD `0d18463` plus accepted uncommitted RX-9104/RX-9105 changes. Earlier work and evidence are preserved. No commit, push, remote issue mutation, deployment, publication or benchmark occurred.

## Implemented

Dropdown displays a captured optional `messages.keyboardHint`: Arrow Up/Down selects a result; Enter opens it or searches without a selection; Escape dismisses results; Tab moves on. A unique `aria-describedby` ID associates that static text with the combobox, outside the live status. No new key handler or shortcut is installed. Inline, directory and cards receive no combobox instructions.

Modal's default `escapeHint` names Close search as the reliable close action and explains that Escape may clear the search field first. Existing hint strings/options remain captured and compatible. Visible hints describe the search input; shortcut text/reference appears only with `shortcut:true`, and `keyboardHints:false` leaves no hint references. The bounded footer is now a named focusable native scroll group, adding one deliberate help stop to Tab traversal so full translations remain readable rather than line-clamped. Its inset focus outline avoids clipping at the dialog boundary.

Key handlers, native editing/link activation, active descendants, composition, query scheduling, idle/reset behavior, initial and settled focus, close/opener restoration, shortcut eligibility, exact totals/ranges and engine/provider behavior are unchanged. Runtime edits are confined to dropdown/modal TS and CSS; the only declaration change is the optional dropdown message field. No dependency or export-map change.
