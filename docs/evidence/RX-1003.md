## Implemented boundary

`executeSearch(root, rawQuery, options?, trace?)` is an internal generator, not a public engine export. It owns bounded raw query/options/trace data at admission, analyzes lexical input once with the shared basic-v1 implementation, and uses one work budget across compilation, expansion, complete membership, scoring and page selection. The initial index root remains revision 0. Prefix enumeration establishes complete live field/term expansions before evaluating any Boolean branch; whole-query counts union distinct pairs across groups. Group membership comes from postings, followed by Boolean/scalar predicates for every live document. Only successful positive groups contribute, deduplicated by canonical identity. Field-local BM25 picks the best weighted term per field and sums fields/groups in deterministic UTF-16 key order.

A resumable worst-first heap holds at most offset + limit candidates, while total always counts the complete qualifying set. Limit zero still validates/expands/evaluates the full query and obtains its exact total. Private opt-in tracing selects explicit IDs, including off-page, nonqualifying and missing IDs, and collects actual evaluator/scorer inputs/intermediates. Header plus complete selected facts have an inclusive 4,096-entry ceiling (reducible per request), and expected-revision mismatch fails explicitly. Normal search allocates no collector, node facts, selected numeric facts or complete explanation tree. Public search options/results and model/analyzer identities remain unchanged; the trace request/result is a private seam for the later Inspector capability.

## Repairs and classification

- **Implementation defect, fixed:** whole-query expansion counting initially summed per-group unique pairs. A cap-1 query containing exact red groups of weights 1 and 0.5 incorrectly failed with actual 2, although both resolve to one field/term pair. Independent review confirmed the distinct-pair contract. Query-wide pair union now passes this case; different fields/terms still consume separate entries. No new product/specification decision was needed. The core contract now states the cross-group union explicitly.
- **Implementation defect, fixed:** a positive legal `Number.MIN_VALUE` variant weight can underflow its weighted contribution to zero. The initial winner condition omitted its trace because the initial best was also zero. A separate presence flag now selects the first present alternative and preserves the term/variant tie rule even at zero; regression and independent probe pass.
- Original-token and native comparison/hash inputs receive explicit work charges. With tracing off, evaluator paths are not built. These changes preserve results and the private cursor boundary.

Final read-only acceptance/documentation review: **Ready**. The reviewer directly reran the full 177-test check, focused 28 tests, both preserved probes and all twelve measurement rows. Fresh measurement JSON matched the entire saved artifact with no excluded fields. Temporary instrumentation independently counted 958 oracle calls; maximum generated AST sizes were 14, 15 and 15 nodes across the three seeds. Portable probe hashes/import-only changes and the updated context/specification claims were verified.

No speedup, latency, bundle-size, memory capacity or cross-host promise follows from these counts.
