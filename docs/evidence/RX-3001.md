# RX-3001 — One-owner module-worker adapter

Date: 2026-10-08. Status: verified locally. Independent review: **Ready with follow-ups**. All six acceptance criteria pass for the recorded host.

## Implemented behavior and public contracts

Optional `/adapters/worker` exports `createWorkerRaveldex`, `WorkerAdapterError`, `WORKER_ERROR_CODES` and readonly client/receipt types. Optional `/adapters/worker/host` exports `serveRaveldexWorker` and host types. Applications explicitly construct their same-host module worker and bundle page/worker as separate ESM entries. Importing core or either adapter entry initializes no workers or host resources. Existing tooling/lockfile, pure ESM, private version `0.0.0` and zero runtime dependencies are preserved.

`createWorkerRaveldex({worker, configuration, ownership: 'owned'|'external', sameHost: true, maxMessageBytes?, responseTimeoutMs?})` returns a frozen bound ordinary-method facade plus `reconcile` and `destroy`. Validated initialization creates exactly one complete native execution owner/root. Duplicate host setup or a second live/initializing client on one endpoint rejects `INCOMPATIBLE_WORKER` without disturbing the first owner; disposal releases those guards. No shards, fallback scorer, automatic retries, snapshots or persistence are added.

Complete schema, limits, implementation/protocol/model/analyzer and capability identities match in both handshake directions. First-party `execution.worker` is true with a versioned exact canonical identity containing every normalized semantic option, including private facet/fact/range/snippet caps. Trusted implementations are imported locally by the host; executable handles never cross transport. Direct-only capabilities remain valid directly and fail worker selection. `basic-v1` remains an unqualified analyzer profile: explicit `sameHost: true` and matching logical identity do not establish cross-host Unicode or native-snapshot portability.

Transport owns plain bounded data without executing accessors. It validates sessions, increasing IDs, supported operations, result counts/order/ties/UTF-16 IDs, mutation counters and typed errors. Encoded UTF-8 JSON envelope bytes include keys and protocol/session/operation metadata. Default/hard cap is 8 MiB, selectable down to 1,024 bytes; handshake takes the stricter host/client cap. Additional caps are 131,072 visited nodes, depth 64, 65,536 array elements, 256 UTF-16 units per key, 64 client pending/host active requests and 128 reserved dispatch slots. Native queue/admission/work/data caps remain independently stricter. ID allocation after native caller capture and ordered dispatch preserve direct admission order under structural-signal reentry. Private worker cancellation is attached after legitimate capture, preserving caller admission cliffs. Monotonic admission time includes capture/transport before native FIFO execution.

Native observed cancellation/deadline errors retain their core code/class. A lost read reply is `TIMEOUT`; an established endpoint failure is `TERMINATED`; pre-handshake endpoint failure is `STARTUP_FAILED`. The reply watchdog defaults to 65,000 ms, selectable from 1–120,000 ms. A dispatched mutation without a conclusive result is `OUTCOME_UNKNOWN` with its operation ID; known commit remains successful. Mutation promises expose readonly session operation IDs. Living owners answer `reconcile(id)` within a 256-receipt window: `pending`, `committed` with the actual result (including successful no-ops), `rejected` with sanitized error, or `expired`. Missing/expired receipts never prove rollback. Disposal settles promises and releases signal/worker listeners and timers, terminating only owned endpoints; acknowledgement timeout still cleans up. Recovery is explicit new-owner/source rebuild.

The documentation pilot selects direct/worker and source/positions over the same allowlisted corpus. Setup changes dispose the previous owner, preserve query text, reset facet/page state and suppress stale mounts. Its local server serves the explicit worker artifact under the same-origin CSP.
