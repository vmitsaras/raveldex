## Runtime behavior and boundaries

Each `executeOwnedSearch` now creates its own root-bound ranking context. The scorer lazily prepares field N/total length/boost/average only after an actual posting match and the original charged scoring boundary. A nested per-field map caches `{df,idf}` by the actual immutable term entry, sharing it across groups that reuse the entry while isolating different fields. Per-posting tf/length and document-dependent normalizer/tf-part/base/weighted checks still execute. Constant statistic validation stays lazy, so an unused malformed field does not create a new eager error. A root-identity guard rejects accidentally supplying another root to the private scorer. The default private scorer context preserves independent-call behavior; genuine search passes one shared context across documents.

The exact average, `Math.log(1 + (N - df + 0.5) / (df + 0.5))`, normalizer, TF-part and boost/weight multiplication expressions and evaluation order remain unchanged. Canonical alternatives/groups/fields, tie behavior and selected actual FieldFact intermediates are unchanged. Filters, page selection and traces never redefine corpus statistics. A later search, mutation, restore or interleaved/reentrant root uses a fresh context; no cache lives on a root, expansion, engine, global or serialized snapshot.

Cache entries are bounded by the query's selected fields and distinct expanded field/term pairs under existing limits. Each miss performs a bounded number of scalar/Map operations; there are no new owned preparation loops or corpus copies. Native Map growth, allocation and GC do not supply a hard constant-time guarantee. The existing coarse matched-scoring charge still covers cache access, remaining validation and document arithmetic; **work policy/units, yielded steps and stop positions are unchanged**. Fewer arithmetic calculations are not presented as fewer work units. No model/API/cap/quantum/dependency/candidate/scheduler/prefix change is made. Retained/peak heap bytes are **Not measured**; the operation-local map bound is not a heap-byte measurement.
