## Scope decision

**Ruling:** perform editorial restructuring in the site renderer and preserve the
original packaged Markdown bytes. Getting started, Hosts and Core are three of
the five indexed source guides, so editing their raw text would change the
explicitly protected indexed contract. `site/reading.mjs` consumes those sources
and the existing core recipe. The cost of this choice is that package Markdown
itself does not gain the site-only reading controls and section grouping.

`Layout.astro` adds guide/reference modes using the existing route registry;
ordinary guide prose is bounded at68ch and reference prose at76ch while code and
tables may use the center column. The right outline hides before the left
navigation collapses. `reading.mjs` is an explicit build input, copied into scratch
Astro only; the existing controller handles copy and lifecycle. No new dependency,
parser, public API, engine, browser permission or consumer/starter change was made.
Other guides/reference pages inherit the code/typography treatment without
speculative content rewrites. Starter source pages retain their existing flow.
