# RX-9403 — Directory and rich result polish

Status: implemented and verified locally after RX-9401/RX-9402 acceptance.

## Findings and changes

Current installed directory/cards passed 37 baseline checks. The baseline
reproduced an empty Results heading and Page 1 of 1 pager despite zero matches,
and exposed a disabled Refresh results action after successful recovery and blur.
New regressions failed before repair ([focus](N14_UI/directory-focus-red.log),
[empty hierarchy](N14_UI/directory-empty-red.log)).

The shared presenter now hides empty headings/lists and a blank pager, and retires
obsolete recovery/navigation controls after native focus leaves. A focused action
stays mounted, visible and guarded through held requests, zero results and refusal;
no implicit focus jump or duplicate request was introduced. State feedback uses
existing tokens and non-color border treatment. Rich metadata has a quiet divider
from excerpts. Public CSS hooks/options remain unchanged.

The selected-zero and OR-within/AND-across count semantics, chip focus ordering,
native disclosure, history replay and image-failure behavior were already correct
and remain covered. Deliberate missing-image fixtures were not falsely recorded
as product failures. No new ranking, filtering, sorting or image-loading policy.
