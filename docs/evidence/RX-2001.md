## Implementation and public contract

Explicit `/addons/phrases` exports `createSourceProvider` and `createSourcePhrases`; `/addons/phrases/source` exports only the source factory. Root runtime exports remain `createRaveldex`, `RaveldexError`, `ERROR_CODES`; readonly registration/handle types are additive. The ordinary frozen seven-method facade and method/result contracts remain unchanged. Configuration `addons` now accepts complete validated trusted direct registrations. Malformed/anonymous registrations reject `INCOMPATIBLE_CAPABILITY` rather than the pre-N2 blanket `MISSING_CAPABILITY`; absent requirements still reject `MISSING_CAPABILITY`. Unsupported protocol/execution/roles fail before initialization. Unknown initializer exceptions are sanitized typed factory failures.

The bounded implemented roles are transactional participants and exact-token-sequence leaf refinement. No arbitrary query predicate or before/after search hook, custom analyzer, aggregation, positions, offsets, snippets, UI, workers, snapshots or live module install/rebuild is added. The source provider retains only selected original field/value arrays in immutable incremental directories, with revision/analyzer headers and logical entry/text caps. All its deltas join the real core transaction and disposal lifecycle. The phrase compiler analyzes input once natively and keeps ordered repeats; complete exact groups form its candidate superset. Streaming native source reanalysis and a <=32-entry prefix table verify only that leaf before scoring/pagination. Surviving groups retain native BM25, alternatives, deduplication and successful-branch participation. Missing provider fields/revision/analyzer/authoritative candidate data fail explicitly.
