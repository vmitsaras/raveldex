Advanced demo settings

Use these settings to compare how search runs. Changing a setting rebuilds the collection, keeps your query and resets the category and page.

  • Representation: check phrases from original text, or use stored word positions and offsets.
  • Execution: run directly, or move the engine to a module worker.
  • Query meaning: complete the final word, require all exact words, or require an adjacent phrase.

Destroy interface removes the controls. Use Reinitialize search to rebuild the collection and bring them back.

Use the controls

Press Tab to move between controls and result links, or Return to submit from the search field. Choose a Category to narrow the matches and All to clear it. Changing page shows more results without changing the total. These updates keep focus on the control you used.

Open Inspect results to see which terms matched and how scores were calculated. Close Inspector or press Escape to return focus to that button. The highlighted snippets are short excerpts; follow a result link to read the complete guide.

Add search to your application

For a small starting point, copy ui.mjs into an application where you installed Raveldex. It creates an engine, adds one document and supplies its display title and URL.

Give the controls a place on the page

Add this HTML where you want search to appear. It stays empty until the JavaScript runs.

<section id="search" aria-label="Documentation search"></section>

Initialize search and load its styles

Put this in a browser module processed by your bundler. Run it after the search element exists.

import { createSearchUI } from './ui.mjs';
import '@vmitsaras/raveldex/addons/ui/styles.css';

const search = await createSearchUI(document.querySelector('#search'));
// When removing the component:
// await search.dispose();

You should see a styled search field and results. Search atomic to find one result, Atomic updates, with a link to /guide/updates/. Your application supplies that destination page.

Clean up and add features when needed

Call await search.dispose() when removing the component. It removes the controls before disposing the engine. This example keeps data in memory and needs no database.

The demo above also enables phrases, facets, snippets and Inspector, using source or offset providers. You can add those later. See UI setup and CSS and optional capabilities.
